# Audio — Talo y el Color del Enojo

Coloca aquí el archivo de audio de la canción.

## Archivo requerido

- `talo-enojo.mp3` — La canción completa

**Formato:** MP3 (128 kbps mínimo, 320 kbps recomendado)

---

**Cómo funciona:**
1. El archivo se copia a `editor-remotion/public/assets/audio/talo-enojo.mp3`
2. Cada composición de reel carga este archivo
3. Remotion lo reproducirá en loop durante los 30 segundos del reel
4. La sincronización es automática

**Nota:** Si la canción no empieza exactamente en segundo 0, avísame y ajusto el offset en el código.
