# TaloInsta — Storyboard de 4 Frames para Instagram Reels

> Skill para crear el storyboard visual de un Reel de Instagram a partir de una canción o fragmento TaloInsta.
> Formato: **4 frames — mini storyboard vertical 9:16**
> Compatible con **Magnific Freepik (Nano Banana Pro 2)** y **Seedance 2**.
> **Estilo visual:** 3D Pixar cartoon — igual que el universo TaloInsta.

---

## DIFERENCIAS CLAVE CON EL STORYBOARD LARGO (8 frames × sección)

| Aspecto | Storyboard largo (YouTube) | Storyboard Reels (Instagram) |
|---------|---------------------------|------------------------------|
| Frames totales | 8 por sección | **4 frames por reel completo** |
| Duración cubierta | 2-3 minutos | **30-45 segundos** |
| Orientación | Horizontal 16:9 | **Vertical 9:16** |
| Ideas visuales | Narrativa completa | **Una sola idea dominante** |
| Frame 1 | Establece escenario | **Hook explosivo en 0-3s** |
| Cierre | Outro de despedida | **Loop o pregunta que invita a repetir** |
| Personajes | 1-4 según narrativa | **Máximo 2 — preferible 1** |
| Cámara | Movimientos variados | **Dinámicos y rápidos — siempre en movimiento** |

## PASO 0 — PREPARACIÓN OBLIGATORIA

1. **Lee `characters/personajes.md`** — Carga los perfiles visuales. Si un personaje tiene `[pendiente]`, notifícalo al usuario.
2. **Lee `learnings/errors-log.md`** — Aplica todas las reglas globales.
3. **Identifica el tipo de reel** según la tabla de `shorts-reels-format.md`:
   - ¿Clip de coro? ¿Clip educativo? ¿Clip de movimiento? ¿Clip loop?

---

## PASO 1 — RECIBIR EL INPUT

El input puede ser:
- **Fragmento de letra** (coro, verso, hook)
- **Concepto educativo** ("reel sobre el color azul")
- **Instrucción de tipo** ("reel de baile con el coro de Respira con Talo")

Extrae:
- **Frase clave** — la línea más repetible y memorable
- **Emoción dominante** — alegría / calma / emoción / curiosidad / movimiento
- **Personaje principal** — siempre Talo como protagonista; secundario opcional
- **Color de Talo** — según la emoción (ver sistema de color en `personajes.md`)
- **Escenario** — uno de los escenarios fijos de la Aldea TaloInsta

---

## PASO 2 — ESTRUCTURA DE 4 FRAMES

Cada reel tiene **exactamente 4 frames** con funciones fijas:

### Frame 1 — GANCHO (0-3 segundos)
**Objetivo:** Capturar atención INMEDIATA. Si el niño o el padre no se queda en este frame, el reel falla.

| Regla | Detalle |
|-------|---------|
| **Plano** | Primer plano (PP) o plano medio muy cerrado (PM cercano) |
| **Personaje** | Talo en el centro absoluto, ocupando 60-70% del encuadre |
| **Expresión** | Explosiva — sorpresa, alegría máxima, curiosidad intensa |
| **Acción** | Movimiento inmediato: saltando, girándose, señalando al espectador |
| **Color de Talo** | El más vivo posible según la emoción (amarillo, naranja, multicolor) |
| **Fondo** | Simple, limpio — que no compita con Talo |
| **Cámara Seedance** | `fast push in` o `dynamic zoom in` |

### Frame 2 — IDEA CENTRAL (3-15 segundos)
**Objetivo:** Comunicar la única idea educativa o emocional del reel.

| Regla | Detalle |
|-------|---------|
| **Plano** | Plano medio (PM) o plano americano (PA) |
| **Personaje** | Talo realizando la acción educativa/emocional principal |
| **Expresión** | Comprometida con la idea — enseñando, mostrando, cantando |
| **Acción** | La acción que define el reel: señalar el color, respirar, saltar, etc. |
| **Color de Talo** | Consistente con Frame 1 |
| **Fondo** | Más rico que Frame 1, escenario reconocible de la aldea |
| **Cámara Seedance** | `gentle zoom in` o `slow pan` siguiendo la acción |

### Frame 3 — CLÍMAX / CALL-TO-ACTION VISUAL (15-25 segundos)
**Objetivo:** Pico de energía emocional + invitar al niño a participar.

| Regla | Detalle |
|-------|---------|
| **Plano** | Primer plano (PP) o plano medio (PM) |
| **Personaje** | Talo mirando directamente al espectador O Talo + 1 amigo en acción conjunta |
| **Expresión** | La más intensa del reel — celebración, invitación, entusiasmo |
| **Acción** | Gesto que el niño puede imitar: aplaudir, señalar, hacer el gesto 1-2-3 |
| **Color de Talo** | Puede intensificarse aquí (multicolor si es celebración) |
| **Fondo** | Más saturado, partículas de luz, destellos — énfasis visual máximo |
| **Cámara Seedance** | `soft push in` centrado en cara, o `static camera` si la acción lo pide |

### Frame 4 — CIERRE EN LOOP (25-35 segundos)
**Objetivo:** Conectar visualmente con Frame 1 para que el loop sea natural. El niño quiere verlo otra vez.

| Regla | Detalle |
|-------|---------|
| **Plano** | Mismo tipo que Frame 1 (callback visual) |
| **Personaje** | Talo solo, en pose que "invita" o "reabre" la acción |
| **Expresión** | Guiño, sonrisa picara, mano extendida — "¿otra vez?" |
| **Acción** | Eco de Frame 1 pero con la emoción transformada/cumplida |
| **Color de Talo** | Verde principal o tono del cierre — no más vivo que Frame 3 |
| **Fondo** | Igual al Frame 1 para reforzar el loop visual |
| **Cámara Seedance** | `gentle zoom out` revelando el personaje completo |

## PASO 3 — GENERAR LOS PROMPTS

Lee los descriptores de `characters/personajes.md` y cópialos literalmente — **nunca improvises la descripción de un personaje**.

### Reglas de composición vertical (9:16)
- Personaje siempre **centrado** horizontalmente
- El sujeto principal ocupa **el tercio central** del encuadre
- Fondos en **bokeh suave** para no competir con el personaje
- Texto/caption siempre en **el tercio inferior** — dejar espacio libre
- **Sin elementos importantes en las esquinas** — se cortan en diferentes dispositivos

---

### PROMPT DE IMAGEN — Magnific Freepik (Nano Banana Pro 2)

**Formato por frame (4 prompts individuales):**
```
[descriptor visual exacto del personaje desde personajes.md], [color de Talo según emoción], [acción específica del frame], centered in frame, [nombre del escenario] background with [2 elementos de fondo máximo — simple], soft bokeh background, portrait 9:16 vertical composition, soft volumetric lighting, vibrant saturated colors, bold colors, 3D Pixar cartoon style, smooth 3D render, expressive character, TaloInsta universe, high quality
```

**Formato del prompt de GRID (1 imagen = 4 paneles en columna vertical):**
```
storyboard sheet with 4 numbered panels in a 2x2 grid, vertical 9:16 reel format, [tema del reel], [personaje con descriptor resumido], [color de Talo], [escenario], soft volumetric lighting, vibrant saturated colors, bold colors, 3D Pixar cartoon style, smooth 3D render, panel 1: [gancho — expresión explosiva], panel 2: [idea central], panel 3: [clímax con gesto participativo], panel 4: [cierre loop conectado con panel 1], clean borders between panels, panels labeled 1 through 4, TaloInsta universe
```

**Notas para Magnific:**
- Prompts en **inglés**
- Siempre incluir `portrait 9:16 vertical composition` o `portrait orientation`
- Siempre incluir `centered in frame` — crítico para composición vertical
- Máximo **2 elementos de fondo** — los reels necesitan claridad visual rápida
- Para el color de Talo: usar `[color] Talo` ej: `bright yellow Talo`, `orange Talo`

---

### PROMPT DE VIDEO — Seedance 2

**Formato por frame (4 clips individuales):**
```
[descriptor visual del personaje], [color de Talo], [acción específica animada], [escenario con 1-2 elementos de fondo], [movimiento de cámara], portrait 9:16 vertical video, 3D Pixar cartoon animation style, soft volumetric lighting, smooth fluid motion, energetic and playful, [X] seconds
```

**Formato del GRID DE VIDEO (1 prompt = secuencia completa de 4 escenas en orden):**
```
3D Pixar cartoon animation, TaloInsta universe, portrait 9:16 vertical format, [personaje(s)] with [descriptor visual resumido], continuous sequence of exactly 4 scenes in strict order without skipping:
Scene 1 — HOOK: [acción explosiva + escenario simple + movimiento de cámara dinámico], [duración]s,
Scene 2 — MAIN IDEA: [acción educativa/emocional + escenario reconocible + movimiento de cámara], [duración]s,
Scene 3 — CLIMAX: [gesto participativo + fondo más saturado + movimiento de cámara intenso], [duración]s,
Scene 4 — LOOP CLOSE: [eco de escena 1 con emoción cumplida + movimiento de cámara que invita a repetir], [duración]s.
Smooth transitions between each scene, consistent character design throughout, vibrant saturated colors, soft volumetric lighting, vertical portrait composition throughout.
```

**Duraciones recomendadas para Reels:**
| Frame | Duración | Razón |
|-------|----------|-------|
| Frame 1 (Gancho) | 3s | Máximo impacto, mínimo tiempo |
| Frame 2 (Idea central) | 7s | Espacio para comunicar la idea |
| Frame 3 (Clímax) | 7s | Pico emocional + participación |
| Frame 4 (Cierre loop) | 3s | Rápido — conecta con inicio |
| **Total** | **~20s** | Base de video; con música ~30-35s |

**Movimientos de cámara para Reels (más dinámicos que el formato largo):**
| Movimiento | Frame ideal | Efecto |
|------------|-------------|--------|
| `fast push in` | Frame 1 | Entrada explosiva |
| `dynamic zoom in` | Frame 1 | Hook inmediato |
| `gentle zoom in` | Frame 2 | Enfoque en la idea |
| `slow pan following action` | Frame 2 | Sigue al personaje |
| `soft push in` | Frame 3 | Énfasis emocional |
| `static camera` | Frame 3 | Deja brillar la expresión |
| `gentle zoom out` | Frame 4 | Revela cierre, invita al loop |
| `slow tilt up` | Frame 4 | Revela el entorno completo |

## NOTAS DE PLATAFORMA (Instagram Reels 2025-2026)

- **Duración óptima:** 30-45s (máxima retención para contenido infantil)
- **Primeros 3 segundos:** determinan si el adulto/niño se queda — NUNCA desperdiciarlos
- **Audio:** la música debe entrar en segundo 0 — sin intro instrumental
- **Texto en pantalla:** siempre en el tercio inferior — el algoritmo lo detecta y genera subtítulos automáticos
- **Loop automático:** si el Frame 4 conecta bien con Frame 1, el algoritmo de Reels lo repite automáticamente — esto multiplica las vistas
- **Thumbnail:** Usar Frame 1 o Frame 3 (el más expresivo) como cover del reel
