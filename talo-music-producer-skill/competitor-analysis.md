# Competitor Analysis — Marco de análisis de competencia

## Objetivo

Extraer patrones estructurales de canciones infantiles virales para informar la composición de canciones de Talo. No se trata de copiar, sino de entender qué funciona y por qué.

## Canales de referencia a monitorear

- Peppa Pig en Español
- Pinkfong / Baby Shark (español)
- CoComelon en Español
- Pocoyo
- Canticuentos
- Smile and Learn
- Lunacreciente

## Variables a extraer por canción analizada

### Estructura
- [ ] Orden de secciones (intro / verso / coro / bridge / outro)
- [ ] ¿Empieza con música instrumental o directamente con letra?
- [ ] ¿Hay narración hablada vs. cantada?

### Timing
- [ ] Duración total de la canción
- [ ] Segundo exacto en que entra el coro por primera vez
- [ ] Duración de la intro
- [ ] Duración de cada sección

### Letra
- [ ] Cantidad total de palabras
- [ ] Número de palabras distintas (vocabulario)
- [ ] Frecuencia del nombre del personaje en la letra
- [ ] Presencia de onomatopeyas (listar)
- [ ] Preguntas directas al oyente (listar)
- [ ] Instrucciones de movimiento (listar)
- [ ] Conteos o series numéricas

### Música y ritmo
- [ ] Tempo aproximado (lento / moderado / rápido / BPM estimado)
- [ ] Cambios de ritmo o tempo dentro de la canción
- [ ] Cortes musicales (silencio o pausa dramática)
- [ ] Instrumentos predominantes
- [ ] Uso de coros de voces infantiles

### Energía por sección
- [ ] Nivel de energía de intro (1–5)
- [ ] Nivel de energía de verso (1–5)
- [ ] Nivel de energía de coro (1–5)
- [ ] Nivel de energía de outro (1–5)

### Animación y visual
- [ ] Momentos de pausa útiles para cambio de escena
- [ ] Sincronía letra–acción visual (¿la letra describe lo que se ve?)
- [ ] Partes interactivas con el espectador

### Distribución
- [ ] ¿Funciona bien en loop?
- [ ] ¿Tiene versión corta / Short?
- [ ] Métricas aproximadas (vistas, likes si disponibles)
