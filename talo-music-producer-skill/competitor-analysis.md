# Competitor Analysis & Reverse Engineering — Canciones infantiles virales

## Objetivo

Extraer patrones estructurales de canciones infantiles virales para informar la composición de canciones originales de Talo. No se trata de copiar, sino de entender qué funciona y por qué, y transformar esos aprendizajes en material 100% original para El Mundo de Talo.

---

## Principio de uso seguro

Las referencias analizadas en este marco se usan **exclusivamente** para extraer:

- Patrones generales de estructura (orden de secciones, timing)
- Comportamiento de energía por sección
- Mecanismos de interacción con el espectador
- Formato y duración óptimos por plataforma

**Nunca** se usan para copiar:

- Letra o fragmentos de letra reconocibles
- Melodías, progresiones de acordes o motivos identificables
- Personajes, nombres, frases distintivas o catchphrases
- Identidad visual, estética de animación o estilo gráfico
- Estructuras tan específicas que sean atribuibles a una canción en particular

Si una referencia es muy famosa o reconocible, aumentar deliberadamente la distancia creativa en todos los elementos.

## Análisis de retención por segundos

La retención del espectador infantil sigue ventanas críticas muy cortas. Cada canción de referencia debe mapearse contra esta estructura:

| Ventana | Qué debe ocurrir |
|---|---|
| **0–3 seg** | Gancho inicial: sonido, voz, palabra o efecto que detenga el scroll |
| **3–10 seg** | Entrada del personaje, pregunta directa o acción llamativa |
| **10–20 seg** | Aparición del motivo principal o frase educativa clave |
| **antes de 20 seg** | Idealmente primer coro o frase repetible ya presente |
| **cada 15–25 seg** | Cambio visual, cambio rítmico o variación que renueve la atención |
| **últimos 10 seg** | Cierre memorable, repetición del hook o transición a loop |

Usar esta tabla para identificar en qué segundo exacto ocurre cada evento en la canción de referencia, y luego replicar el **ritmo de atención**, no el contenido.

## Variables musicales avanzadas

### Ritmo y tempo
- [ ] BPM estimado (escuchar y contar, o usar herramienta)
- [ ] Compás probable (4/4, 3/4, 6/8...)
- [ ] Patrón rítmico dominante (marcado, shuffle, sincopado, etc.)
- [ ] Cambios de ritmo o variaciones de tempo dentro de la canción
- [ ] Cortes o silencios dramáticos (ubicación y duración)

### Melodía y voz
- [ ] Rango melódico aproximado (¿cuántas notas distintas en el coro?)
- [ ] Tipo de voz principal (infantil, adulta femenina, adulta masculina, mixta)
- [ ] Presencia de coros infantiles o adultos
- [ ] Call-and-response (pregunta cantada / respuesta esperada)
- [ ] Repetición del hook o frase principal (¿cuántas veces aparece?)

### Instrumentación y producción
- [ ] Instrumentos protagonistas
- [ ] Efectos especiales o sonidos de ambiente
- [ ] Onomatopeyas musicalizadas
- [ ] Densidad de producción (minimalista / media / full)

### Letra y densidad
- [ ] Densidad de palabras por sección (alta / media / baja)
- [ ] Longitud media de líneas cantadas (en palabras)

## Variables de letra y aprendizaje

### Contenido educativo
- [ ] Objetivo educativo principal de la canción
- [ ] Edad estimada del público objetivo
- [ ] Vocabulario nuevo que introduce
- [ ] Repetición de palabras clave (¿cuáles y cuántas veces?)

### Participación e interacción
- [ ] Instrucciones de movimiento corporal (listar)
- [ ] Preguntas directas al niño (listar)
- [ ] Momentos de participación familiar
- [ ] Partes de call-and-response en letra

### Claridad y accesibilidad
- [ ] Claridad de pronunciación (palabras simples vs. complejas)
- [ ] Riesgo de exceso de palabras por línea
- [ ] Frases de más de 8 palabras (marcar como alerta)

---

## Variables visuales y de animación

### Estructura visual
- [ ] Acción principal por sección (¿qué se ve en intro, verso, coro?)
- [ ] Frecuencia de cambio de plano o escena
- [ ] Cambio de color, objeto o personaje entre secciones

### Sincronía y storyboard
- [ ] Sincronía letra–acción (¿la animación refuerza lo que se canta?)
- [ ] Momentos de pausa útiles para interacción o pregunta visual
- [ ] Potencial para armar storyboard basado en la estructura
- [ ] Potencial para versión Shorts/Reels (¿hay un clip de 30–50 seg que funcione solo?)

## Matriz de extracción

Usar esta tabla para transformar observaciones en decisiones creativas originales:

| Elemento observado | Qué significa | Cómo aplicarlo a Talo sin copiar |
|---|---|---|
| **Coro temprano** (antes de 20 seg) | Alta retención inicial, el niño reconoce la canción rápido | Diseñar coro de Talo con entrada antes de los 20 seg, melodía propia |
| **Pregunta directa al niño** | Activa participación y prolonga atención | Incluir pregunta en verso o bridge de Talo con su propio tema |
| **Onomatopeya** | Imitable, divertida, activa expresión vocal | Crear onomatopeya original asociada al tema de la canción |
| **Cambio de ritmo** | Renueva atención, evita aburrimiento | Planificar un momento de contraste en la estructura de Talo |
| **Pausa interactiva** | Espera respuesta del niño, crea vínculo | Insertar pausa dramática de 1–2 seg antes del coro final |
| **Repetición del nombre del personaje** | Refuerza identidad de marca | Mencionar "Talo" al menos 2 veces por sección clave |
| **Loop final** | Maximiza tiempo de visualización en YouTube Kids | Diseñar outro que conecte naturalmente con el intro |

## Limitación importante: referencias de YouTube

### Problema

Cuando el usuario proporciona links de YouTube para analizar como referencias, Claude puede encontrar un error **HTTP 403 Forbidden**. Esto ocurre porque:

- YouTube requiere acceso autenticado a algunos videos desde contextos no navegador
- La API de web scraping que usa Claude puede no tener autorización para ciertos videos
- El video puede estar geobloqueado o tener restricciones de acceso

### Regla de procedimiento

Cuando el usuario entrega un link de YouTube como referencia:

1. **Intentar acceder** — Claude usa WebFetch para obtener información del video
2. **Si acceso exitoso (200 OK)** — proceder con análisis de patrones normal
3. **Si error 403 Forbidden** — no forzar el acceso; aplicar procedimiento alternativo
4. **Si error de timeout u otro** — aplicar procedimiento alternativo
5. **Ser transparente** — comunicar al usuario exactamente qué pasó y por qué
6. **Solicitar alternativa** — pedir información manual que reemplace el acceso automático

### Procedimiento cuando video de YouTube no es accesible

**Paso 1: Comunicar el problema**
```
No puedo acceder directamente a este video de YouTube (error 403 Forbidden).
Para continuar con el análisis, necesito que me proporciones:
```

**Paso 2: Solicitar información alternativa (elegir al menos 2)**

- [ ] **Descripción manual** — ¿Qué ocurre en el video sección por sección? (intro, verso, coro, puente, outro)
- [ ] **Estructura de timestamps** — ¿A qué segundos ocurren los eventos principales? (0:00 intro, 0:15 coro, etc.)
- [ ] **Letra completa o fragmentos clave** — ¿Qué dice la canción, especialmente el coro y hook?
- [ ] **Observaciones musicales** — Tempo (¿rápido/lento?), instrumentos principales, energía
- [ ] **Observaciones visuales** — Acciones del personaje por sección, cambios de escena, interacción
- [ ] **Referencia de canción conocida** — ¿Tiene un patrón similar a otra canción que SÍ podemos analizar juntos?

**Paso 3: Proceder con análisis**
Con la información proporcionada, aplicar el marco de análisis normal (matriz de extracción, plantilla de análisis profundo, patrones, riesgos).

### Ejemplo de respuesta transparente

```
Intenté acceder a: [URL]
Error: HTTP 403 Forbidden

Para continuar con el análisis de patrones, necesito que me ayudes proporcionando:

1. ¿Cuál es la estructura de la canción? 
   (ej: intro 5 seg → verso 15 seg → coro 20 seg → verso 15 seg → coro 20 seg → outro 5 seg)

2. ¿En qué segundo aparece el gancho o frase memorable?
   (ej: "en el segundo 5, escuchas el hook")

3. ¿Cuál es el objetivo educativo?
   (ej: "enseña los colores primarios")

4. ¿Qué movimientos o acciones hace el personaje?
   (ej: "salta, gira, levanta los brazos")

Con esta información, puedo analizar patrones generales y ayudarte a crear la canción de Talo.
```

## Salida esperada después del análisis

Cuando Claude completa el análisis de una o más referencias, debe producir:

1. **Resumen de patrones comunes** — qué comparten las canciones analizadas en timing, estructura y energía
2. **Oportunidades para Talo** — qué patrones se pueden adaptar de forma original
3. **Riesgos de copyright** — elementos específicos que deben evitarse
4. **Propuesta de estructura original** — secciones, duración y orden para la canción de Talo
5. **Recomendaciones de ritmo y arreglo** — BPM, instrumentación, cambios de energía
6. **Prompt Mureka original en inglés** — listo para copiar y pegar, basado exclusivamente en patrones generales extraídos, sin reproducir nada específico de las referencias
