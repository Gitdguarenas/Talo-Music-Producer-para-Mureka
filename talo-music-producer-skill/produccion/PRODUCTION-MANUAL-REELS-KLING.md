```

```

### TIPO 2: GENERADO KLING 2.5 (video AI)
```
INPUT: 
  - IMAGEN_INICIAL: Prompt para Nano Banana 2 (qué personaje, emoción, posición)
  - KLING_PROMPT: Descripción detallada del movimiento/transformación
  - NEGATIVE: Lo que NO quieres
  - DURATION: 10 segundos

OUTPUT: Video clip único
TIMING: 10 seg exacto
USO: Transformaciones, emociones intensas, momentos pegajosos, cambios de color
```

### TIPO 3: MONTAJE HÍBRIDO (frame + transición + frame)
```
Frame 1 (3s) → Transición Kling (4s) → Frame 2 (3s)
Kling genera solo la transición, no el contenido narrativo
```

## PARTE 10: NOTAS TÉCNICAS IMPORTANTES

### Para NANO BANANA 2:
```
SIEMPRE incluir en el prompt:
- "3D Pixar cartoon style, smooth 3D render"
- "soft volumetric lighting"
- Descriptor exacto del personaje (color, emoción, expresión)
- Escenario (plaza del gran árbol, etc.)
- "TaloInsta universe"
- "high quality"
- Tamaño recomendado: 1080×1920 (vertical reel)
```

### Para KLING 2.5:
```
ESTRUCTURA DE INPUT:
1. IMAGEN: Generada con Nano Banana 2 (ver prompts arriba)
2. PROMPT: Descripción detallada del movimiento (10-12 líneas)
3. NEGATIVE PROMPT: Lo que NO queremos (8-10 líneas)
4. DURATION: 10 segundos EXACTO

TIPS:
- El prompt debe incluir MOVIMIENTO (no pueden ser estáticas)
- Describir con VERBOS de acción (moves, transforms, spins, etc.)
- Timing específico dentro del prompt si hay transiciones
- Cámara: describe siempre el ángulo de cámara (close-up, full body, etc.)
- Color: si Talo cambia de color, describe la transición ("slowly becomes green")
```

### Para Timing en Reel:
```
CLIP DE 10s = máximo en Kling
FRAME DE 3-5s = máximo en storyboard

Si necesitas un clip de 15s:
Opción A: Usar dos clips Kling de 7-8s cada uno (con transición)
Opción B: Usar 1 clip Kling (10s) + 1 frame (5s)
Opción C: Usar montaje de frames storyboard

NUNCA hacer un clip Kling de +10s (el modelo tiene límites)
NUNCA dejar frame estático >5s (baja engagement)
```

### Para Audio:
```
La canción debe estar DISPONIBLE en:
- Formato MP3 (alta calidad)
- Duración: 2:55 (para la canción "Talo y el Enojo")

Para Kling 2.5:
- Generar clip SIN audio (ambiente mudo)
- Agregar la canción EN POST-PRODUCCIÓN (Capcut, Adobe Express, etc.)
- Sincronizar visualmente con picos emocionales de la música

Para Reels:
- La canción corre de INICIO A FIN
- Ajustar video al timing de la canción, NO al revés
```

## EJEMPLO: CÓMO EJECUTAR REEL 3 PASO A PASO

### Workflow:

```
PASO 1: Generar imágenes iniciales con NANO BANANA 2

  → Imagen 1 (Sección A): 
    Prompt: "Split screen: left red angry Talo, right green calm Talo..."
    
  → Imagen 2 (Sección B):
    Prompt: "Talo the chameleon in DEEP RED-ORANGE color, angry..."
    
  → Imagen 3 (Sección D):
    Prompt: "Talo in calm BRIGHT GREEN with Rubí beside him..."

PASO 2: Generar videos con KLING 2.5

  → Video 1 (Sección B - 10s):
    Input Image: Imagen 2 (Talo rojo)
    Prompt: "Talo is FURIOUS. He jumps up and down..."
    Negative: "calm pose, green color, subtle emotion..."
    Duration: 10 segundos
    
  → Video 2 (Sección C - 4s):
    Input Image: Imagen 2 final (Talo rojo)
    Prompt: "Talo freezes. Light surrounds him..."
    Negative: "no light, still pose, violent..."
    Duration: 4 segundos (pero sigue parámetro max 10s)
    
  → Video 3 (Sección D - 10s):
    Input Image: Imagen 3 (Talo verde)
    Prompt: "Talo takes a deep breath. His whole body relaxes..."
    Negative: "anger, red color, frustration..."
    Duration: 10 segundos

PASO 3: Compilar en editor de video (Capcut, Adobe Express, IG native)

  - Arrastrar: Sección A (3s)
  - Arrastrar: Video 1 (10s)
  - Agregar: Transición luz (4s = Video 2)
  - Arrastrar: Video 3 (10s)
  - Arrastrar: Sección E (3s)
  
  TOTAL: 30 segundos

PASO 4: Audio

  - Importar MP3 de la canción
  - Sincronizar START de video con START de canción
  - Volumen: -6dB para que texto sea legible si hay narración

PASO 5: Texto en pantalla

  - 0-3s: "ANTES 🔴"
  - 3-13s: "¿Te pasa a ti?"
  - 13-17s: "Respira conmigo..."
  - 17-27s: "¡Lo intentó de nuevo!"
  - 27-30s: "¿Quieres saber cómo? YouTube 👆"

PASO 6: Exportar

  - Formato: MP4 (1080×1920, vertical)
  - Calidad: Alta (no comprimir demasiado)
  - Frame rate: 30fps

PASO 7: Subir a Instagram

  - Copiar caption (ver PARTE 12)
  - Copiar hashtags (ver PARTE 12)
  - Horario: Según schedule (ver PARTE 12)
  - Link en bio: YouTube
```
