# E06 — LOS NÚMEROS (1–5)

## 📋 FICHA TÉCNICA

| Campo | Valor |
|---|---|
| **Episodio** | E06 — Semana 8 |
| **Tipo** | Educativa (Números) |
| **Duración** | ~1:45 |
| **Personajes** | Talo (aprendiz), Nuti (dulce, apoyo) |
| **Escenario** | Selva, río, árbol |
| **Concepto central** | Contar del 1 al 5 con ejemplos visuales |
| **Subtemas (3)** | 1. Contar dedos | 2. Objetos naturales | 3. Amigos |
| **Rimas** | AABB |
| **Público** | 2–3 años (principalmente) |

## 🎵 ESTRUCTURA SUGERIDA

### [Intro Hablado] — 10 seg
```
Talo y Nuti,
¡vamos a contar!
Números del uno al cinco,
¡aprendamos hoy!
```

### [Verso 1] — "Contar con dedos" (~25 seg)
**Subtema:** Uno, dos, tres, cuatro, cinco dedos de la mano

```
Tengo una mano,
con dedos para contar.
Uno, dos, tres, cuatro, cinco,
dedos, dedos a contar.
```

**Detalles visuales:**
- Talo muestra su mano
- Cada dedo se levanta (1, 2, 3, 4, 5)
- Nuti imita
- Expresión alegre

### [Verso 2] — "Objetos en la selva" (~25 seg)
**Subtema:** Flores, frutas, piedras, etc.

```
Una flor amarilla,
dos frutas en el árbol.
Tres piedras, cuatro hojas,
cinco, cinco, ¡qué bonito!
```

**Detalles visuales:**
- Mostrar cada objeto (1 flor, 2 frutas, 3 piedras, 4 hojas)
- Énfasis en 5 de algo (ej: 5 mariposas)

### [Verso 3] — "Amigos contando" (~25 seg)
**Subtema:** Personajes del universo

```
Un Talo, dos Nutis,
tres búhos en el cielo.
Cuatro Rubís, cinco Tucos,
¡amigos a contar!
```

**Detalles visuales:**
- Aparecer cada personaje en orden
- Contar juntos en pantalla

### [Coro] — "Los Números están aquí" (~30 seg)
```
Uno, dos, tres, cuatro, cinco,
números en la selva están.
Talo, Nuti y sus amigos,
contamos siempre sin parar.

Dedos, flores, piedras, hojas,
todo podemos contar.
Uno, dos, tres, cuatro, cinco,
¡números a jugar!
```

**Nota:** Este coro debe sonar MUY rítmico y repetible. Los niños lo cantarán muchas veces.

### [Outro] — "Repaso lento" (~20 seg)
```
Uno…
dos…
tres…
cuatro…
cinco…

¡Contamos con Talo!
```

## 🎨 GRIDS SUGERIDOS (si es animado)

Si se anima con Nano Banana 2 + Seedance 2:
- **GRID 1 (Verso 1):** Talo mostrando dedos (5 frames mostrando cada dedo)
- **GRID 2 (Verso 2):** Objetos en selva (flores, frutas, piedras, hojas, mariposas)
- **GRID 3 (Verso 3):** Personajes apareciendo uno a uno
- **GRID 4 (Coro):** Todos los personajes cantando juntos

**Escenario:** Selva clara, bien iluminada. Árbol grande, flores coloridas, río al fondo.

# E07 — LOS ANIMALES DE LA SELVA

## 📋 FICHA TÉCNICA

| Campo | Valor |
|---|---|
| **Episodio** | E07 — Semana 9 |
| **Tipo** | Educativa (Naturaleza) |
| **Duración** | ~2:00 |
| **Personajes** | Talo (explorador), Búho (maestro), Rubí (exploradora) |
| **Escenario** | Selva profunda, canopy, río |
| **Concepto central** | Biodiversidad — animales de la selva |
| **Subtemas (3)** | 1. Felinos (jaguar) | 2. Aves (loro, tucán) | 3. Pequeños (insectos, serpientes) |
| **Rimas** | ABAB |
| **Público** | 3–5 años |

## 🎵 ESTRUCTURA SUGERIDA

### [Intro Hablado] — 12 seg
```
Talo, Rubí y Búho,
explorar queremos.
¡La selva tiene animales!
¡Vamos a conocerlos!
```

### [Verso 1] — "Felinos" (~30 seg)
**Subtema:** Jaguar (manchado, fuerte, silencioso)

```
En la selva está el jaguar,
con manchas de oro y negro.
Fuerte, silencioso, hermoso,
jaguar, jaguar, ¡lo veo!
```

**Detalles visuales:**
- Jaguar de perfil, manchas claramente visibles
- Movimiento ágil
- Expresión noble, no amenazante

### [Verso 2] — "Aves" (~30 seg)
**Subtema:** Loro, tucán (coloridos, ruidosos, sociales)

```
El loro vuela y canta,
rojo, verde, amarillo.
Tucán con pico grande,
pájaro, pájaro, bonito.
```

**Detalles visuales:**
- Loro volando (rojo, verde, amarillo)
- Tucán con pico prominente
- Interacción entre ellos

### [Verso 3] — "Pequeños del suelo" (~30 seg)
**Subtema:** Serpientes, insectos, anfibios

```
Una serpiente en el árbol,
cambia de color, es Talo-amiga.
Ranas, hormigas, mariposas,
pequeños, pequeños, ¡aquí!
```

**Detalles visuales:**
- Serpiente verde moviéndose
- Ranas saltando
- Mariposas volando
- Insectos caminando en la tierra

### [Coro] — "Animales de la Selva" (~35 seg)
```
Jaguar, loro, tucán están,
en la selva a vivir.
Ranas, serpientes, mariposas van,
en la naturaleza a jugar.

Talo, Rubí y Búho saben,
que la selva es hermosa.
Todos los animales juntos,
¡hacen la selva preciosa!
```

### [Outro] — "Repaso con admiración" (~20 seg)
```
El jaguar… noble
Las aves… coloridas
Los pequeños… especiales

¡La selva tiene vida!
¡Gracias, animales!
```

## 🎨 GRIDS SUGERIDOS

- **GRID 1 (Verso 1):** Jaguar en diferentes ángulos (cazador pacífico)
- **GRID 2 (Verso 2):** Loro y tucán volando, interactuando
- **GRID 3 (Verso 3):** Pequeños animales (serpiente, rana, mariposa, insectos)
- **GRID 4 (Coro):** Todos los personajes (Talo, Búho, Rubí) con los animales

**Escenario:** Selva densa, canopy visible, luz filtrada, árbol gigante, río.

## 🔍 PALABRAS CLAVE SEO

- "animales de la selva en español"
- "biodiversidad para niños"
- "canciones sobre la naturaleza"
- "educación ambiental infantil"

# E08 — MIS FORMAS (Círculo, Cuadrado, Triángulo)

## 📋 FICHA TÉCNICA

| Campo | Valor |
|---|---|
| **Episodio** | E08 — Semana 10 |
| **Tipo** | Educativa (Formas geométricas) |
| **Duración** | ~1:45 |
| **Personajes** | Talo (curioso), Tuco (social/mediador) |
| **Escenario** | Selva + objetos geométricos del mundo |
| **Concepto central** | 3 formas básicas: círculo, cuadrado, triángulo |
| **Subtemas (3)** | 1. Círculo | 2. Cuadrado | 3. Triángulo |
| **Rimas** | AABB |
| **Público** | 3–4 años |

## 🎵 ESTRUCTURA SUGERIDA

### [Intro Hablado] — 10 seg
```
Talo y Tuco,
¡mira alrededor!
Formas en la selva,
¡vamos a explorar!
```

### [Verso 1] — "El Círculo" (~25 seg)
**Subtema:** Círculo (redondo como luna, sol, frutas)

```
Redondo, redondo como la luna,
o como el sol que brilla.
Círculo, círculo sin fin,
rueda, rueda, ¡qué bonito!
```

**Detalles visuales:**
- Luna circular en el cielo
- Sol circular brillante
- Fruta circular (naranja)
- Rueda del círculo girando
- Talo señalando cada uno

### [Verso 2] — "El Cuadrado" (~25 seg)
**Subtema:** Cuadrado (4 lados iguales, piedra, cabaña)

```
Cuatro lados, todos iguales,
cuadrado soy.
Como la puerta de mi casa,
cuadrado, cuadrado, ¡eso soy!
```

**Detalles visuales:**
- Puerta de cabaña (cuadrada)
- Ventana (cuadrada)
- Piedra cuadrada
- Caja de regalo
- Líneas que marcan los 4 lados

### [Verso 3] — "El Triángulo" (~25 seg)
**Subtema:** Triángulo (3 lados, montaña, techo, vela)

```
Tres lados unidos,
triángulo soy.
Como la montaña grande,
triángulo, triángulo, ¡lo voy!
```

**Detalles visuales:**
- Montaña triangular
- Techo de cabaña (triangular)
- Vela de barco triangular
- Líneas mostrando los 3 vértices

### [Coro] — "Las Formas están aquí" (~30 seg)
```
Círculo, cuadrado, triángulo,
formas en la selva están.
Talo y Tuco las encuentran,
en cada lugar, en cada pan.

Redondo, cuadrado, puntiagudo,
formas de formas son.
Círculo, cuadrado, triángulo,
¡todas con nosotros!
```

### [Outro] — "Repaso visual" (~18 seg)
```
Redondo…
Cuadrado…
Triángulo…

¡Formas alrededor!
```

## 🎨 GRIDS SUGERIDOS

- **GRID 1 (Verso 1):** Círculos en la naturaleza (luna, sol, frutas, flores)
- **GRID 2 (Verso 2):** Cuadrados en la naturaleza y construcciones
- **GRID 3 (Verso 3):** Triángulos en la naturaleza (montañas, árboles puntiagudos)
- **GRID 4 (Coro):** Talo y Tuco señalando todas las formas juntos

**Escenario:** Selva con montaña al fondo, cabaña clara, sol, luna.

## 🔍 PALABRAS CLAVE SEO

- "enseñar formas geométricas"
- "círculo cuadrado triángulo"
- "matemáticas para preescolares"

# E09 — GRANDE Y PEQUEÑO

## 📋 FICHA TÉCNICA

| Campo | Valor |
|---|---|
| **Episodio** | E09 — Semana 11 |
| **Tipo** | Educativa (Tamaños/Comparación) |
| **Duración** | ~1:45 |
| **Personajes** | Talo (mediano), Inta (grande/materna), Nuti (pequeña) |
| **Escenario** | Selva con contrastes de tamaño |
| **Concepto central** | Comparación de tamaños: grande, mediano, pequeño |
| **Subtemas (3)** | 1. Animales grandes | 2. Medianos | 3. Pequeños |
| **Rimas** | ABAB |
| **Público** | 3–4 años |

## 🎵 ESTRUCTURA SUGERIDA

### [Intro Hablado] — 10 seg
```
Talo, Inta y Nuti,
tamaños diferentes somos.
¡Grande, mediano y pequeño!
¡Vamos a comparar!
```

### [Verso 1] — "Grande" (~25 seg)
**Subtema:** Animales/cosas grandes

```
El árbol es muy grande,
llega al cielo.
Inta es grande, protectora,
grande, grande, ¡lo veo!
```

**Detalles visuales:**
- Árbol gigante (tronco grueso, ramas altas)
- Inta apareciendo, imagen grande
- Contraste: Talo pequeño cerca del árbol
- Letras "GRANDE" en mayúsculas grandes

### [Verso 2] — "Mediano" (~25 seg)
**Subtema:** Cosas medianas (Talo es mediano)

```
Talo es mediano,
ni grande ni pequeño.
Como la rama del árbol,
mediano, mediano, ¡es genial!
```

**Detalles visuales:**
- Talo de tamaño normal
- Rama mediana que puede sostener
- Taco mediano (no gigante, no minúsculo)
- Letras "MEDIANO" en tamaño medio

### [Verso 3] — "Pequeño" (~25 seg)
**Subtema:** Cosas pequeñas

```
Nuti es pequeña, dulce,
como la flor.
Semillas, hormigas, gotas,
pequeño, pequeño, ¡qué amor!
```

**Detalles visuales:**
- Nuti pequeña en pantalla
- Flor pequeña
- Semilla en la mano
- Hormiga caminando
- Gota de agua cayendo
- Letras "PEQUEÑO" en letras chiquitas

### [Coro] — "Tamaños diferentes" (~30 seg)
```
Grande, mediano, pequeño,
todos somos especiales.
Talo, Inta y Nuti juntos,
tamaños diferentes, igual de valiosos.

El árbol grande, la flor pequeña,
la rama mediana también.
Todos los tamaños cuentan,
¡en la naturaleza y en la vida!
```

### [Outro] — "Repaso con aceptación" (~18 seg)
```
Grande…
Mediano…
Pequeño…

¡Todos especiales!
```

## 🎨 GRIDS SUGERIDOS

- **GRID 1 (Verso 1):** Talo pequeño cerca de árbol gigante, Inta grande
- **GRID 2 (Verso 2):** Talo en posición "mediana", rama mediana
- **GRID 3 (Verso 3):** Nuti pequeña, flores, semillas, hormigas
- **GRID 4 (Coro):** Los tres personajes juntos mostrando sus tamaños

**Escenario:** Selva con variación de escalas (árbol gigante, plantas medianas, insectos pequeños).

# E10 — LA ALEGRÍA

## 📋 FICHA TÉCNICA

| Campo | Valor |
|---|---|
| **Episodio** | E10 — Semana 12 |
| **Tipo** | Emocional (positiva) |
| **Duración** | ~2:00 |
| **Personajes** | Talo (protagonista), Rubí (energía), Tuco (diversión) |
| **Escenario** | Selva en fiesta, luz dorada |
| **Concepto central** | Alegría — expresar felicidad, celebrar, reír |
| **Fases (3)** | 1. Descubrimiento (algo hace feliz) | 2. Expresión (reír, saltar, cantar) | 3. Celebración (con amigos) |
| **Rimas** | AABB |
| **Público** | 2–5 años |
| **Especial** | Primera canción emoción POSITIVA después de Enojo |

## 🎵 ESTRUCTURA SUGERIDA

### [Intro Hablado] — 12 seg
```
Talo descubre algo hermoso,
¡la risa en la selva!
La alegría nos calienta el corazón,
¡vamos a celebrar!
```

### [Verso 1] — "Descubrimiento de la alegría" (~30 seg)
**Fase:** ¿Qué hace que nos sintamos alegres?

```
Una mariposa vuela,
¡qué bonita es!
Mi corazón se llena de luz,
alegría, alegría, ¡lo siento!
```

**Detalles visuales:**
- Talo ve una mariposa colorida
- Su expresión cambia a sonrisa
- Líneas de luz alrededor del pecho (corazón)
- Ojos brillando de alegría
- NO exageración, natural

### [Verso 2] — "Expresión de la alegría" (~30 seg)
**Fase:** Cómo expresamos la alegría (reír, saltar, cantar)

```
Río sin parar,
salto, doy vueltas.
Mi voz canta sin pensar,
alegría, alegría, ¡es bonito!
```

**Detalles visuales:**
- Talo sonriendo ampliamente
- Saltando, dando vueltas
- Boca abierta (risa)
- Movimientos libres, dinámicos
- Rubí uniéndose a los saltos

### [Verso 3] — "Celebración con amigos" (~30 seg)
**Fase:** La alegría es más grande cuando está con otros

```
Rubí y Tuco vienen,
con nosotros a jugar.
Juntos nos reímos,
alegría, alegría, ¡sin parar!
```

**Detalles visuales:**
- Los tres personajes juntos
- Todos sonriendo
- Movimiento colectivo (baile, juego)
- Luz cálida iluminando a todos
- Ambiente de celebración

### [Coro] — "La Alegría nos une" (~35 seg)
```
Alegría en el corazón,
brilla como el sol.
Reír, saltar, cantar,
¡eso es sentirse bien!

Talo, Rubí y Tuco juntos,
celebran la vida.
Alegría en la selva,
¡la compartimos!
```

**Nota:** Este coro debe sonar LUMINOSO, con voces armónicas de los tres personajes.

### [Outro] — "Cerrar con paz y alegría" (~20 seg)
```
Cuando siento alegría…
Mi corazón brilla…
Con mis amigos…
¡La vida es hermosa!
```

## 🎨 GRIDS SUGERIDOS

- **GRID 1 (Verso 1):** Talo con mariposa, descubrimiento (luz suave alrededor del pecho)
- **GRID 2 (Verso 2):** Talo saltando, riendo (movimiento dinámico)
- **GRID 3 (Verso 3):** Talo, Rubí, Tuco juntos celebrando
- **GRID 4 (Coro):** Todos con manos arriba, sonriendo, luz dorada

**Escenario:** Selva con luz dorada, flores abiertas, luz solar filtrada, ambiente cálido.

## 🔍 PALABRAS CLAVE SEO

- "emociones positivas para niños"
- "alegría infantil"
- "canciones de felicidad"
- "educación emocional preescolar"

# E11 — EL DÍA Y LA NOCHE (Rutinas)

## 📋 FICHA TÉCNICA

| Campo | Valor |
|---|---|
| **Episodio** | E11 — Semana 13 |
| **Tipo** | Educativa (Rutinas, ciclos naturales) |
| **Duración** | ~2:00 |
| **Personajes** | Talo (aprendiz), Inta (guía), Búho (noche) |
| **Escenario** | Selva en transición (mañana → noche) |
| **Concepto central** | Ciclo diario: mañana, tarde, noche — rutinas |
| **Subtemas (3)** | 1. Mañana (actividad, sol) | 2. Tarde (juego) | 3. Noche (descanso, Búho vigila) |
| **Rimas** | ABAB |
| **Público** | 3–5 años |
| **Especial** | Ayuda con rutinas del niño (hora de dormir) |

## 🎵 ESTRUCTURA SUGERIDA

### [Intro Hablado] — 12 seg
```
El día tiene tres momentos,
mañana, tarde y noche.
Talo, Inta y Búho,
¡conocemos cada momento!
```

### [Verso 1] — "La Mañana" (~30 seg)
**Subtema:** Amanecer, sol, actividad, aventura

```
El sol sale en la mañana,
calienta mi corazón.
Es hora de despertar,
explorar, explorar, ¡es hora!
```

**Detalles visuales:**
- Sol saliendo por el horizonte
- Cielo anaranjado/rosado
- Talo despertando, estirándose
- Inta haciendo actividades (recoger frutas)
- Energía clara, movimientos rápidos

### [Verso 2] — "La Tarde" (~30 seg)
**Subtema:** Luz más baja, juego, descanso parcial

```
La tarde es tiempo de jugar,
el sol está más bajo.
Corremos, nos divertimos,
jugar, jugar, ¡qué bonito!
```

**Detalles visuales:**
- Luz más dorada (atardecer)
- Sombras más largas
- Talo, Inta, Tuco jugando juntos
- Energía moderada pero alegre
- Cielo con colores cálidos

### [Verso 3] — "La Noche" (~30 seg)
**Subtema:** Oscuridad (como Oscuridad), descanso, Búho vigila

```
Llega la noche, la oscuridad,
es hora de descansar.
Búho vigila con cuidado,
dormir, dormir, ¡es hora!
```

**Detalles visuales:**
- Cielo oscuro, luna saliendo
- Talo en cama, ojos cerrándose
- Búho en rama, vigilante
- Luz lunar suave
- Ambiente tranquilo
- Inta durmiendo también

### [Coro] — "El día tiene ciclos" (~35 seg)
```
Mañana, tarde, noche,
el día gira sin parar.
Despertar, jugar y descansar,
es el ritmo natural.

Talo, Inta y Búho saben,
que cada momento es perfecto.
Mañana, tarde, noche,
¡todos tienen su respeto!
```

### [Outro] — "Cerrar con tranquilidad nocturna" (~20 seg)
```
Cuando llega la mañana…
exploramos…
Cuando llega la tarde…
jugamos…
Cuando llega la noche…
¡descansamos!
```

## 🎨 GRIDS SUGERIDOS

- **GRID 1 (Verso 1):** Amanecer, sol saliendo, Talo despertando, actividad
- **GRID 2 (Verso 2):** Luz de atardecer, personajes jugando, energía media
- **GRID 3 (Verso 3):** Noche oscura, luna, Talo durmiendo, Búho vigilante
- **GRID 4 (Coro):** Ciclo completo (mañana → tarde → noche visible en transición)

**Escenario:** Selva que cambia de iluminación (amanecer → tarde dorada → noche lunar).

**Lo que hace:** Condensa las letras principales de cada episodio en 2–3 líneas cada una

**Estructura:**
```
[Verso 1: Presentación + Colores] — 15 seg
Soy Talo, tengo colores,
rojo, azul y amarillo...

[Verso 2: Amigos + Vocales] — 15 seg
Somos amigos, A E I O U,
aprendemos juntos cada día...

contamos uno, dos, tres, cuatro, cinco...

grande, mediano, pequeño...

TODOS LOS PERSONAJES CANTAN JUNTOS
```

### [Sección de Agradecimiento] — ~30 seg
**Lo que hace:** Talo y los amigos agradecen al espectador directamente

```
[Talo hablando directamente a cámara]
"Gracias, amigo, por explorar conmigo.
Aprendimos colores, números, emociones.

[Todos los personajes juntos]

¡todos tus amigos en la selva!"
```

**Detalles visuales:**
- Talo grande en primer plano, mirando a cámara
- Otros personajes apareciedo detrás/alrededor
- Todos sonriendo
- Luz cálida dorada

### [Teaser Temporada 2] — ~15 seg
**Lo que hace:** Genera expectativa para continuar

```
[Escena misteriosa: Puerta cerrada en la selva, o huella de algo desconocido]
```

**Detalles visuales:**
- Ambiente misterioso pero no asustador
- Puerta, brújula, huella, o elemento que sugiera "lo desconocido"
- Música tensión-curiosidad (no miedo)
