# ESTRUCTURA DE CANCIÓN INFANTIL — GUÍA INTEGRAL TALO
**Integración de estructura clásica infantil + patrones Luli Pampín + episodios emocionales**

---

## 🎯 DOS TIPOS DE CANCIONES TALO (Sistema definitivo — 2026-05-19)

Talo tiene **dos tipos de canciones**. Antes de crear cualquier canción, debes determinar el tipo.

---

### TIPO A — CANCIÓN EMOCIONAL NARRATIVA
**Cuándo usar:** La canción trata de superar o procesar una emoción o problema.
- Enojo, miedo, tristeza, vergüenza, celos, soledad, frustración, exclusión, sentirse diferente
- Ejemplo: "Talo y el Color del Enojo", "Talo y la Oscuridad", "Talo y los Celos de Nuti"
- Referencia: **Canticuénticos** (narrativa desarrollada + coros muy pegajosos)

| Parámetro | Valor |
|---|---|
| **Duración** | 2:50 – 3:00 max |
| **Total frases** | 24 – 32 |
| **Tamaño verso** | 8-12 palabras/línea (más narrativo) |
| **Versos totales** | 4-5 (cuentan la historia emocional) |
| **Coro** | 4-5 líneas, IDÉNTICO siempre, MUY pegajoso — tiene ritmo + frase potente. Onomatopeya **opcional** |
| **Coro aparece** | 3 veces mínimo |
| **BPM** | 85-95 BPM intro, sube a 110-120 BPM en pico emocional, baja a 85-90 BPM en resolución |
| **Estructura** | Intro hook → Verso 1 (setup) → Verso 2 (frustración crece) → Coro → Verso 3 (pico + validación) → Bridge/Pausa (2 seg silencio) → Verso 4 (resolución) → Coro × 2 → Outro |

**Coro ideal para Tipo A:**
```
✅ MUY PEGAJOSO + NARRATIVO (coro enojo):
"¡Estoy enojado, está bien!
Respira profundo conmigo,
uno... dos... tres...
¡Las manos tranquilas construyen mejor!"

✅ OTRO EJEMPLO (coro miedo):
"No estoy solo, aquí están
Rubí, Tuco y Nuti,
respira conmigo,
¡estoy protegido aquí!"

❌ DEMASIADO SIMPLE (no suficientemente narrativo para Tipo A):
"Respira con Talo, uno, dos y tres"
(solo 1 línea corta = no suficiente para una canción narrativa)
```

---

### TIPO B — CANCIÓN SIMPLE PEGAJOSA
**Cuándo usar:** Todo lo que NO sea superar una emoción/problema.
- Movimiento, baile, animales, colores, rutinas, números, vocales, partes del cuerpo, diversión, energía
- Ejemplo: "Los Colores de Talo", "Baila con Talo", "Talo y los Animales de la Selva"
- Referencia: **Luli Pampín + Pequeño Pez** (energía, anticipación, repetición)

| Parámetro | Valor |
|---|---|
| **Duración** | 2:00 – 2:30 |
| **Total frases** | 18 – 24 |
| **Tamaño verso** | 5-8 palabras/línea (corto, directo) |
| **Versos totales** | 3 (Repetidor + Elemento Variador) |
| **Coro** | 3-4 líneas simples, IDÉNTICO siempre. Puede incluir onomatopeya pero no es obligatorio |
| **Coro aparece** | 3-4 veces |
| **BPM** | 105-128 BPM constante (energético todo el tiempo) |
| **Estructura** | Intro hook (onomatopeya/frase) → Verso 1 → Coro → Verso 2 → Coro → Verso 3 → Coro → Outro |

**Coro ideal para Tipo B:**
```
✅ EJEMPLO (canción vocales):
"Súbete al tren, ven, súbete al tren
chu-cu-chu-cu-chu
a las vocales vamos a recoger
¡A - E - I - O - U!"

✅ EJEMPLO (canción baile):
"¡Salta, salta, salta con Talo!
¡Una, dos, tres!
¡Mueve los brazos arriba!
¡Así, así, así!"

✅ EJEMPLO (animales):
"¡El sapito salta, plas!
¡El pájaro vuela, fiu!
¡Talo los imita
porque puede hacerlo tú!"
```

---

### REGLAS UNIVERSALES (aplican a AMBOS tipos)

1. **CORO IDÉNTICO** — Nunca varía entre repeticiones
2. **BPM MÍNIMO 85** — Excepto canciones para dormir (60-80 BPM)
3. **HOOK antes de 10 seg** — Frase o sonido que engancha de inmediato
4. **Sin papá/mamá** — Solo Talo, Rubí, Tuco, Nuti
5. **Vocabulario simple** — Palabras que niños 2-6 usan a diario
6. **Coro aparece 3+ veces** — Siempre más coro que verso en tiempo total

---

### CÓMO DECIDIR EL TIPO

```
¿La canción trata de que Talo supera algo difícil? 
(enojo, miedo, tristeza, vergüenza, celos, frustración, sentirse solo)
   → SÍ → TIPO A (Canción Emocional Narrativa)
   → NO → TIPO B (Canción Simple Pegajosa)
```

## SECCIÓN 1: PARTES CLAVE DE LA CANCIÓN (Estructura Base)

### 1.1 INTRODUCCIÓN (Intro) — 8-16 segundos
**Función:** Prepara el entorno y permite anticipación. Hook explosivo que engancha en primeros 3 segundos.

**Características:**
- Onomatopeya pegajosa (¡Pam!, ¡Pío!, ¡Splash!)
- Tempo energético (85-95 BPM para suave, 110-130 BPM para energético)
- Instrumentación clara y distinta (ukulele, marimba, glockenspiel)
- Frase memorable en primeros 5-10 segundos

**Ejemplos Talo:**
```
✅ "¡Uno, dos, tres! ¡Los cubos aquí!"
✅ "¡Cierro los ojos! ¡Qué oscuro está!"
❌ "Talo despierta en la mañana..." (demasiado lento, sin gancho)
```

### 1.2 VERSO (Estrofa) — Acción + Narrativa Corta
**Función:** Cuenta la historia o presenta la acción. Debe ser SHORT con oraciones directas y ritmo constante.

**Características:**
- Máximo 3 líneas (patrón Luli Pampín validado)
- Máximo 5 palabras por línea
- Acciones concretas, no descriptivas
- Rimas AABB naturales (no forzadas)
- Ritmo constante (no cambios abruptos)

**Estructura por emoción:**

```
ENOJO — Verso de Construcción/Caída:
"Uno, dos, tres,
los cubos van subiendo.
Rojo, verde, azul,
¡cuántos voy a poner!"

MIEDO — Verso de Sonidos/Incertidumbre:
"¡Cierro los ojos!
¿Qué es ese ruido?
Oscuro, oscuro,
¿dónde estoy?"

TRISTEZA — Verso de Ausencia:
"Mi amigo no está,
lo echo de menos.
Recuerdo sus risas,
su voz tan hermosa."
```

**Patrón Verso Repetidor + Elemento Variador (Luli Pampín):**
```
VERSO REPETIDOR (estructura idéntica):
"¡Rojo como la manzana!
¡Splash! ¡Qué hermoso!"

ELEMENTO QUE VARÍA:
Rep 1: "Amarillo como el sol"
Rep 2: "Azul como el cielo"
Rep 3: "Verde como la hoja"

BENEFICIO: Memorización + Novedad simultáneamente
```

### 1.3 CORO (Estribillo) — Pegajoso + Memorable
**Función:** LA PARTE MÁS IMPORTANTE. Contiene la frase principal/mensaje central. Se repite varias veces para memorización.

**Características:**
- 3-4 líneas (NO 2, que es demasiado corto)
- UNA sola idea principal (no múltiples conceptos)
- Rimas AABB perfectas
- IDÉNTICO cada vez que aparece (cero variaciones)
- Se repite 3+ veces en la canción (más coro que verso)
- Mensaje POSITIVO (especialmente en episodios emocionales)
- Llamada a la acción o reafirmación emocional

**Estructura Coro Pegajoso:**
```
✅ BIEN (3-4 líneas, idea única, pegajoso):
"Respira con Talo,
uno, dos y tres.
Manos tranquilas,
construyen mejor."

ANÁLISIS:
- Idea principal: RESPIRACIÓN + CALMA = CONSTRUCCIÓN MEJOR
- Rima: Talo/tres (imperfecta pero fluida), tres/mejor (perfecta)
- Acción: "respira" es verbo imperativo que niños entienden
- Repetibilidad: 8 palabras fáciles de memorizar

❌ MAL (demasiado corto, vago):
"Respira con Talo" (solo 3 palabras = no pegajoso)

❌ MAL (demasiado narrativo/largo):
"Somos amigos especiales, ven a conocer,
cada uno es diferente pero igual hermano,
juntos en la aldea reímos y aprendemos,
en la noche de estrellas siempre seremos." 
(4 líneas pero 4 ideas diferentes = confuso)
```

**Patrones de Coro por Emoción:**
```
ENOJO: Validación + Regulación
"Está bien estar enojado,
respira con calma.
Las manos tranquilas
construyen mejor."

MIEDO: Seguridad + Compañía
"No estoy solo aquí,
mis amigos son.
Estoy protegido,
puedo descansar."

TRISTEZA: Esperanza + Recuerdos
"Te recuerdo con cariño,
tu risa en mi corazón.
Aunque no estés aquí,
estoy bien."

CELOS: Confianza + Inclusión
"Cada uno es especial,
somos diferentes es de verdad.
Juntos somos más fuertes,
no me falta nada."
```

### 1.4 PUENTE (Bridge) — Cambio Ritmo + Sorpresa
**Función:** Pequeño descanso musical o cambio de ritmo que rompe la monotonía y agrega sorpresa.

**Características:**
- Cambio de tempo (más rápido O más lento que versos/coros)
- Cambio de instrumentación (menos o más reverb, sonidos nuevos)
- Pueden incluir: sonidos de animales, onomatopeyas, spoken word, breathing guide
- Duración: 5-10 segundos
- NO debe ser coro repetido (debe ser diferente)

**Ejemplos para Talo:**
```
ENOJO — Puente de Pausa + Validación (hablado, suave):
[Silence - 2 seconds]
"Está bien, Talo.
Tu torre era bella.
Es difícil.
Está bien sentirlo."

MIEDO — Puente de Guía de Respiración (susurrado):
"Respira lentamente,
uno, dos y tres.
El aire entra suave,
estás seguro."

TRISTEZA — Puente de Recuerdo (nostálgico, suave):
[Pausa musical]
"Recuerdo cuando reías..."

CELOS — Puente de Afirmación (energético, con campanas):
"¡Yo soy especial!
¡Yo soy único!
¡Nadie es como yo!"
```

### 1.5 FINAL (Outro) — Cierre + Baja Intensidad
**Función:** Cierre breve que BAJA intensidad y advierte a niños que la canción terminó. Puede incluir call-to-action o reafirmación.

**Características:**
- 2-3 líneas máximo
- Baja intensidad (tempo más lento, volumen menor)
- Puede ser: coro resumido, verso final corto, o CTA
- Debe sonar como "adiós" o conclusión clara
- Tempo: 10-15 segundos

**Ejemplos Talo:**
```
ENOJO:
"Intento otra vez,
sin miedo yo voy.
Con mis amigos,
construimos mejor hoy."

MIEDO:
"Duermo seguro,
mis amigos aquí.
Mañana despierto,
fuerte y feliz."

TRISTEZA:
"Te llevo en mi corazón,
siempre recordaré.
Nuevos amigos llegarán,
seguiré adelante."

CELOS:
"¡Somos todos especiales!
¡Todos juntos somos más!
¡Mureka, emociones,
Talo es mi lugar!"
```

## SECCIÓN 2: PATRONES LULI PAMPÍN (Pegajosidad Comprobada)

### Patrón 1: Verso Repetidor + Elemento Variador
**Por qué funciona:** Familiaridad (genera memoria) + Novedad (previene aburrimiento)

```
VERSO REPETIDOR (IDÉNTICO):
"El cerdo Celestino nada quiere comer,
Solo comida fina asada por un chef."

VERSO VARIADOR (ELEMENTO CAMBIA):
"¡Hola, Celestino! Te traje zanahorias, ¡riquísimo!"
"¡Celestino, Celestino! ¡Te traje manzanas!"
"¡Ay, Celestino! ¡Te traje calabaza!"

APLICACIÓN TALO:
Verso Repetidor: "Talo quiere construir, una torre sin fin"
Verso Variador: "Los cubos rojo, los cubos azul, los cubos verde..."
```

### Patrón 2: Onomatopeyas Pegajosas (Primeros 5-10 segundos)
**Por qué funciona:** Sonidos simples = fácil de imitar, más memorable que palabras

```
✅ ONOMATOPEYAS EFECTIVAS:
"Pío, pío, pío" (La Gallina Puso Huevitos)
"¡Pam! ¡Pam!" (Torre cayendo)
"¡Splash!" (Agua)
"¡Crunch!" (Sonido asustador)
"¡Fuchila!" (Asco cómico)

❌ EVITAR:
Onomatopeyas que suenan agresivas
Múltiples onomatopeyas a la vez (confunde)
Onomatopeyas sin contexto emocional claro
```

### Patrón 3: Repetición de Palabras Clave
**Por qué funciona:** Neurocognitiva - 3 repeticiones = memorización automática

```
CANCIÓN: "No Me Quiero Bañar"
"No me quiero bañar, no me quiero bañar
Así cochina me voy a quedar.
No me gusta el shampoo, no me gusta el jabón
Así cochina me siento mejor."

PALABRAS REPETIDAS:
- "no me quiero" (x2)
- "cochina" (x2)
- "no me gusta" (x2)

APLICACIÓN TALO:
"Respira con Talo, uno, dos y tres.
Cuando te enojes, respira también.
[CORO repetido x3]"
```

### Patrón 4: Diálogo/Interacción
**Por qué funciona:** Niños sienten que pueden cantar una parte, se sienten incluidos

```
RESPUESTAS ESPERADAS:
"¿Ah, no?" ← Niño responde
"¿Cómo de que no?" ← Niño responde
"¿Querés probar?" ← Niño responde "Sí!"

APLICACIÓN TALO:
Verso: "¿Estás asustado, Talo?"
Coro: "Sí, pero estoy aquí."
```

### Patrón 5: Rimas AABB Naturales (No Forzadas)
**Por qué funciona:** Oído de niños detecta rimas = satisfacción auditiva

```
BIEN (AABB natural):
bañar / quedar (A)
shampoo / mejor (B)

BIEN (rima interna):
"Pica, pica, pica el cascarón"
"Nacieron pollitos del color del sol"

MAL (forzada):
"Talo está aquí / en la puerta del salir"
(puerta y salir no riman bien)
```

### Patrón 6: Vocabulario Simple + Cotidiano
**Por qué funciona:** Niños 2-6 entienden palabras que usan diariamente

```
✅ PALABRAS TALO:
cubos, colores, amigos, miedo, oscuridad, respirar, tranquilo, enojo, abrir

❌ EVITAR:
"epifanía", "ambigüedad", "contempla", "quizás"
```

### Patrón 7: Historias Narrativas Cortas + Completas
**Por qué funciona:** Estructura cerebral de niños pequeños sigue: Setup → Conflicto → Resolución

```
SETUP: "A Tito pollito lo llama su mamá"
CONFLICTO: "Pero el pollo Tito se va más allá"
ACCIÓN: "Como no hizo caso, a un hoyo se cayó"
RESOLUCIÓN: "Tito fue valiente, de un salto salió"

4 LÍNEAS = 1 HISTORIA COMPLETA
(NO dejar historias incompletas)
```

### Patrón 8: Exageración Cómica (No Aterrador)
**Por qué funciona:** Humor amable = Niños ríen, memorizan más fácil

```
HUMOR AMABLE:
"Tu pelo va a parecer
Una escoba de barrer" ← Gracioso, no asustador

"De color vas a cambiar,
Como queso de gruyer" ← Gracioso, olor absurdo

EVITAR:
"Te comería un cocodrilo" ← Aterrador
"Tu pelo se caerá" ← Demasiado real, no cómico
```

### Patrón 9: Menos Verso, Más Coro (Proporción)
**Por qué funciona:** Cuanto más se repite el coro, más memorable

```
DISTRIBUCIÓN IDEAL:
- Verso 1 (3 líneas)
- Coro (3-4 líneas) × 1
- Verso 2 (3 líneas)
- Coro (3-4 líneas) × 1
- Verso 3 (3 líneas)
- Coro (3-4 líneas) × 1
- Outro (2-3 líneas)

CÁLCULO: 9 líneas verso + 12 líneas coro = CORO ES 57% DE LA CANCIÓN
(El elemento más pegajoso debe ocupar más espacio)
```

### Patrón 10: Estructura + Ritmo Bouncy
**Por qué funciona:** Niños saltan, aplauden, el ritmo facilita movimiento

```
RÍTMO BOUNCY:
"Pío, pío, pío, pío" (sílabas iguales, tempo rápido, saltable)
"Respira con Talo, uno, dos y tres" (ritmo constante, aplaudible)

NO BOUNCY:
"Cuando contemplo la noche estrellada..." (irregular, no saltable)
```

## ⚠️ IMPORTANTE ANTES DE LEER SECCIÓN 3

**SECCIÓN 3 es una REFERENCIA de momentos emocionales, NO un checklist obligatorio.**

Las canciones exitosas NO necesitan todas las 7 fases. Muchas usan solo 3-4:
- Hook (onomatopeya)
- Verso pegajoso × 2
- Coro repetido × 3  
- Outro

**El objetivo es PEGAJOSIDAD, no completud narrativa.**

Si agregas todas las 7 fases en cada canción, la duración sube a 4+ minutos y baja la memorabilidad. MALO.

Usa SECCIÓN 3 como inspiración para momentos emocionales musicales, no como estructura que debe estar 100% presente.

## SECCIÓN 3: ESTRUCTURA 7-FASES EMOCIONAL (Referencia, NO Obligatoria)

Los siguientes son momentos emocionales OPCIONALES que puedes usar en tus canciones. No todos necesitan aparecer en cada episodio.

### Fase 1: Setup Tranquilo (0-15 seg) — Intro + Verso 1
**Objetivo:** Establecer escena, presentar problema de forma suave

**Tempo:** 85 BPM | **Instrumentación:** Suave (ukulele, glockenspiel, piano)
**Ejemplo - Enojo:** "Talo quiere construir, una torre sin fin. Uno, dos, tres, los cubos van subiendo."

### Fase 2: Frustración Creciente (15-45 seg) — Verso 2
**Objetivo:** Intensidad aumenta, problema se complica

**Tempo:** 95 BPM | **Instrumentación:** Agrega marimba, aumenta volumen
**Ejemplo - Enojo:** "Se tambalea, se tambalea, casi casi se va. Un cubo, dos cubos, ¿cuántos más van a caer?"

### Fase 3: Explosión Emocional (45-60 seg) — Verso 3 + Inicio de Puente
**Objetivo:** Emoción en su máximo punto, VALIDACIÓN EMOCIONAL

**Tempo:** 115 BPM | **Instrumentación:** Completa, energía alta
**Ejemplo - Enojo:** "¡Rojo, rojo, rojo! ¡Se fue la paciencia! ¡No es justo, no! ¡Quiero gritar!"

**CRÍTICO:** NO MINIMIZAR. El verso debe VALIDAR la emoción.
```
✅ "¡Quiero gritar! ¡Está mal!" (valida emoción)
❌ "No te enojes mucho" (minimiza)
```

### Fase 4: Pausa Emocional (60-75 seg) — Puente de Validación
**Objetivo:** Dar espacio para respirar, validar sentimiento

**Tempo:** 75 BPM | **Instrumentación:** Mínima, posiblemente silencio de 2 seg
**Ejemplo - Enojo (hablado, susurrado):** "Está bien, Talo. Tu torre era bella. Es difícil. Está bien sentirlo."

**CRÍTICO:** Este es el momento de mayor vulnerabilidad emocional. Debe ser EXPLÍCITAMENTE validante.

### Fase 5: Intervención (75-105 seg) — Verso 4 (Amigos llegan)
**Objetivo:** Aparecen amigos/apoyo, no está solo

**Tempo:** 85 BPM | **Instrumentación:** Cálida, agregamos sonidos nuevos
**Ejemplo - Enojo:** "Rubí, Tuco y Nuti, vienen a ayudar. 'No estás solo, Talo, estamos aquí.'"

**Patrón:** Siempre entran 3 de los 4 amigos (Rubí panda roja, Tuco tucán, Nuti nutria)

### Fase 6: Resolución Calmada (105-135 seg) — Verso 5 + Coro Final
**Objetivo:** El niño regula emoción, vuelve a intentar, encuentra paz

**Tempo:** 85 BPM | **Instrumentación:** Cálida, integración
**Ejemplo - Enojo:** "El rojo se apaga, llega el verde. Las manos tranquilas, construyen mejor. [CORO FINAL]"

**Leitmotif Transform:** La motif musical que comenzó ASCENDENTE/RÁPIDA ahora es DESCENDENTE/LENTA

### Fase 7: Integración (135-180 seg) — Outro
**Objetivo:** Refuerzo positivo, cierre, preparación para dormir/siguiente actividad

**Tempo:** 85 BPM | **Instrumentación:** Fade suave
**Ejemplo - Enojo:** "Intento otra vez, sin miedo yo voy. Con mis amigos, construimos mejor hoy."

## SECCIÓN 4: VALIDACIÓN EMOCIONAL (Checklist Crítico)

**Cada episodio debe validar emociones, NUNCA minimizarlas.**

### Validación en Lyrics:
```
✅ VALIDANTE:
"Está bien estar enojado, respira con calma"
"Tu miedo es real, pero estás protegido"
"Es difícil, y está bien sentirlo"
"Tus lágrimas son válidas"

❌ MINIMIZANTE:
"No es para tanto"
"No tengas miedo"
"No te enojes"
"Deja de llorar"
"Otros tienen problemas peores"
```

### Validación en Estructura:
- **Verse 3:** Emoción en su pico (NO suavizada)
- **Bridge:** Validación explícita (hablada, susurrada)
- **Verse 4:** Presencia de amigos (no adultos/papás)
- **Verso 5:** Transformación + coro positivo
- **Outro:** Reafirmación: "Intento otra vez, con mis amigos"

### Validación en Leitmotif:
- **Frustración Motif (Ascendente):** DO-RE-MI-RE-DO en tempo rápido (80-115 BPM)
- **Pausa Silence:** 2 segundos absolutos (el silencio valida que "siento esto realmente")
- **Calm Motif (Descendente):** DO-LA-SOL-LA-DO en tempo lento (75-85 BPM)

## SECCIÓN 5: MOVIMIENTO + GESTOS (Invitación a Acción)

**Cada sección debe invitar movimiento físico para que niños participen activamente.**

### Intro (Gancho):
```
GESTO: Saltar en el cuarto con energía
CORO EN VOZ: "¡Uno, dos, tres! ¡Los cubos aquí!"
RITMO: Bouncy, 85-95 BPM
```

### Verso 1 (Construcción):
```
GESTO: Levantar brazos hacia arriba (construcción de torre)
VOZ: "Los cubos van subiendo"
MOVIMIENTO: Lento, deliberado
```

### Verso 2 (Frustración):
```
GESTO: Movimiento tembloroso, vacilante
VOZ: "Se tambalea, se tambalea"
MOVIMIENTO: Irregular, trastabillante
```

### Verso 3 (Explosión):
```
GESTO: Tirar brazos abajo (CAÍDA)
VOZ: "¡Se cayó mi torre!"
TEMPO: Rápido, 115 BPM
IMPACTO: PAUSA DE 2 SEGUNDOS (silencio es parte del movimiento)
```

### Puente (Validación):
```
GESTO: Abrazarse a sí mismo
VOZ: Susurrada, lenta
RITMO: 75 BPM, muy lento
INTENCIÓN: "Me siento protegido"
```

### Verso 4 (Amigos):
```
GESTO: Abrir brazos hacia los lados (amigos llegando)
VOZ: "Rubí, Tuco y Nuti, vienen a ayudar"
MOVIMIENTO: Expansivo, acogedor
```

### Verso 5 (Resolución):
```
GESTO: Respiración profunda + manos tranquilas colocando cubos
VOZ: "Las manos tranquilas, construyen mejor"
MOVIMIENTO: Deliberado, calmado, concentrado
```

### Coro (Repetido 3x):
```
GESTO: Seguir respiración con movimiento (inhala brazos arriba, exhala brazos abajo)
VOZ: "Respira con Talo, uno, dos y tres"
PARTICIPACIÓN: Niño canta Y se mueve simultáneamente
```

### Outro:
```
GESTO: Volver a colocar cubos lentamente, cierre sereno
VOZ: Fade suave
MOVIMIENTO: Preparación para siguiente actividad o dormir
```

## SECCIÓN 6: APLICACIÓN PRÁCTICA A TALO

### Checklist de Verificación Antes de Entregar

**PRIORIDADES (en orden de importancia):**

```
🔴 CRITICOS — SIN ESTOS, LA CANCIÓN FALLA:

PEGAJOSIDAD:
☐ Hook en primeros 10 seg: Onomatopeya o frase repetida (¡Pam!, ¡Uno, dos, tres!)
☐ Coro: 3-4 líneas, IDÉNTICO todas las veces, aparece 3+ veces
☐ Verso anticipable: Patrón repetidor + elemento variador (niño predice próximo verso)
☐ Duración: 2:20-2:50 minutos MÁXIMO (si es más, baja la pegajosidad)
☐ BPM: 85+ MÍNIMO (excepto canciones para dormir)

ESTRUCTURA MÍNIMA:
☐ Intro: Hook explosivo (onomatopeya o frase pegajosa)
☐ Verso 1: 3 líneas máximo, 5 palabras por línea
☐ Coro: 3-4 líneas, aparece 3+ veces
☐ Outro: Cierre claro

🟡 IMPORTANTES — MEJORAN MUCHO LA CALIDAD:

CONTENIDO EMOCIONAL:
☐ Validación: Momento donde la emoción es VALIDADA (no miniminizada)
☐ Refrán pegajoso: Una frase se repite 3+ veces (ej: "Respira con Talo")
☐ Amigos no adultos: Si aparecen adultos, son Rubí/Tuco/Nuti, NO mamá/papá

LULI PAMPÍN (Memorabilidad):
☐ Verso Repetidor + Variador: Estructura igual, elemento cambia
☐ Onomatopeyas: Presentes (¡Pam!, ¡Splash!, ¡Toc-toc-toc!)
☐ Rimas AABB: Natural, no forzada
☐ Vocabulario simple: Palabras edad 2-6 años

🟢 OPCIONALES — SOLO SI SIRVEN A LA PEGAJOSIDAD:

ESTRUCTURA EXTENDIDA (7 fases):
☐ Verso 2: Intensidad aumenta (pero no obligatorio)
☐ Verso 3: Pico emocional + validación (pero no obligatorio)
☐ Puente/Bridge: Cambio de ritmo, respiro (pero no obligatorio)
☐ Verso 4: Amigos intervienen (pero no obligatorio)
☐ Verso 5: Resolución (pero no obligatorio)

MOVIMIENTO:
☐ Gesto para Intro (saltar, levantarse)
☐ Gesto para Coro (respirar, aplaudir)
☐ Outro sugiere siguiente actividad

PRODUCCIÓN:
☐ Metatags válidos: [Intro], [Verse], [Chorus], [Bridge], [Spoken], [Silence]
☐ Sin metatags de acción: [Talo se cae], [Amigos llegan] → Pasar a Production Notes
☐ Style Prompt separado: Descripción musical concreta (500 chars máx)
☐ Lyrics en bloque: Solo metatags + narrativa
```

**REGLA DE ORO:** Si algo NO sirve a la pegajosidad, elimínalo. Una canción corta y pegajosa (2:20) vale más que una larga y completa (3:30).
