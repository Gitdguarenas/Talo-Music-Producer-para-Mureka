## MH Checklist (Must-Have de evaluación rápida)

Antes de enviar a Mureka, verifica estos 9 Must-Haves. Si cualquiera falla → rechaza y reescribe.

| # | Criterio | Cómo verificar | Pasa/Falla |
|---|---|---|---|
| 1 | Letra en español latino | ¿Sin modismos regionales? ¿Neutral? | [ ] ✅ [ ] ❌ |
| 2 | Prompt Mureka en inglés | ¿El Style Prompt está en inglés? | [ ] ✅ [ ] ❌ |
| 3 | Talo activo siempre | ¿Talo es el sujeto en cada verso? (no pasivo) | [ ] ✅ [ ] ❌ |
| 4 | Sin palabras prohibidas | Revisa contra children-song-rules.md | [ ] ✅ [ ] ❌ |
| 5 | Edad especificada | ¿2–3 / 3–4 / 4–5 / 5–6 está clara? | [ ] ✅ [ ] ❌ |
| 6 | Hook claro (0–5 seg) | ¿Pregunta, frase repetible o sorpresa? | [ ] ✅ [ ] ❌ |
| 7 | Coro antes seg 20 | ¿El coro entra antes de segundo 20? | [ ] ✅ [ ] ❌ |
| 8 | Intro corta (<7 seg) | ¿Intro es máximo 7 segundos? | [ ] ✅ [ ] ❌ |
| 9 | BPM apto para edad | Revisa rhythm-and-arrangement.md | [ ] ✅ [ ] ❌ |

**Resultado:** Si todos son ✅ → Listo para Mureka. Si alguno es ❌ → Rechaza y reescribe.

## BPM Quick Chart

| Tipo de Canción | BPM | Acción Ideal |
|---|---|---|
| Saludo tranquilo | 90–100 | Moverse lentamente, saludar |
| Números/Colores/Letras | 95–110 | Contar, apuntar, explorar |
| Danza/Movimiento | 110–120 | Bailar, marchar |
| Movimiento energético | 120–130 | Saltar, girar rápido |
| Rutina tranquila | 80–95 | Comer, bañarse, calmar |
| Sueño/Relajación | 60–80 | Respirar, descansar |

## Densidad de Palabras Rápida

| Rango de edad | Palabras máx por línea | Palabras máx por verso | Nota |
|---|---|---|---|
| 2–3 años | 4–5 palabras | 10–15 total | Súper cortas, pausas entre versos |
| 3–4 años | 5–6 palabras | 15–20 total | Aún simple, espacio para procesar |
| 4–5 años | 6–7 palabras | 20–25 total | Puede ser más denso pero cuidado |
| 5–6 años | 7–8 palabras | 25–30 total | Máximo permitido; complejidad conceptual |

## Onomatopeyas Seguras (Top 5 por edad)

**Edades 2–3:** ¡Muu! ¡Guau! ¡Pío! ¡Splash! ¡Pam!
**Edades 3–4:** ¡Pío! ¡Splash! ¡Zip! ¡Whoosh! ¡Plic!
**Edades 4–5:** ¡Crash! (gentle) ¡Pío pío! ¡Ñam! ¡Brum! ¡Shhh!
**Edades 5–6:** ¡Crunch! ¡Oh! ¡Brum! ¡Tututú! ¡Whoosh!

**Nunca usar:** ¡Boom! ¡Thunder! ¡Explosión! ¡Screech! ¡Growwwl!

## Decision Tree: ¿Qué hacer con una canción generada?

```
¿Pasó los 9 Must-Have?
    ├─ SÍ (9/9)
    │   └─ ¿Pasó Should-Have? (8+ de 35)
    │       ├─ SÍ → ✅ APROBADA
    │       └─ NO → Pasa evaluation-checklist.md completo
    │
    └─ NO (< 9/9)
        ├─ ¿Cuántos fallaron?
        │   ├─ 1 Must-Have → Ajustar prompt, regenerar
        │   ├─ 2–3 Must-Have → Ajustar lyrics + prompt, regenerar
        │   └─ 4+ Must-Have → RECHAZAR Y REESCRIBIR desde cero
        │
        └─ ¿Cuál falló?
            ├─ Hook (MH6) → Revisar primeros versos, hacer pregunta o sorpresa
            ├─ Coro timing (MH7) → Mover coro antes de verso 2
            ├─ BPM (MH9) → Cambiar número en Style Prompt
            ├─ Densidad (no es MH pero afecta) → Reducir palabras por línea
            └─ Talo activo (MH3) → Verificar Talo es sujeto principal
```

¿Dónde vas a usar la canción? Optimiza según esto:

| Factor | YouTube Kids | Shorts/Reels | Spotify | Loop educativo |
|---|---|---|---|---|
| **Hook timing** | Seg 3–5 | Seg 0–2 (crítico) | Seg 0–3 | Integrado en estructura |
| **Duración ideal** | 1:45–2:15 | 0:35–0:45 | 2:00–2:30 | 0:45–1:30 |
| **Coro entrada** | Seg 8–12 | Seg 3–5 | Seg 10–15 | Primeros 20 seg |
| **Densidad música** | Media | Alta (cada segundo cuenta) | Media-Alta | Simple, repetible |
| **Interactividad** | Media (pausa clara) | Mínima (rápido) | Baja | Alta (pausas 2 seg) |

| **BPM óptimo** | 100–115 | 115–135 | 90–120 | 90–115 |
| **Outro** | Limpio | Claro/Call-to-action | Fade posible | Loop natural |

## Pre-Submission Checklist (Última verificación antes de Mureka)

Copia y verifica estos 15 puntos. Si todos son ✅, envía.

```
METADATA:
[ ] Título descriptivo en español
[ ] Objetivo educativo en 1 línea
[ ] Edad objetivo clara (2–3, 3–4, 4–5, 5–6)
[ ] Duración esperada especificada

LYRICS:
[ ] Cada línea tiene máx 6–7 palabras (verificar contando)
[ ] Coro aparece antes de segundo 20 (verificar timing)
[ ] Hook es claro en primeros versos (pregunta, sorpresa, repetible)
[ ] [Pausa] tags tienen duraciones (mínimo 2 segundos)
[ ] Talo es sujeto activo (no pasivo) en cada verso
[ ] Sin palabras de prohibited list en children-song-rules.md
[ ] Español latino neutro (sin regionalismos)

STYLE PROMPT:
[ ] Completamente en inglés (no español)
[ ] Incluye: edad, tipo vocal, BPM, mood, instrumentos
[ ] Copiado exactamente de production-templates.md (o correctamente adaptado)
[ ] BPM coincide con rhythm-and-arrangement.md

NEGATIVE GUIDANCE:
[ ] Incluido y específico del tema
[ ] Tomado de production-templates.md (Matriz: Negative Guidance por Tema)

PRODUCTION NOTES:
[ ] BPM numérico especificado
[ ] Duración total clara (1:30–2:15, o específica)
[ ] Claridad vocal mencionada si es tema de pronunciación
[ ] Pausas mínimas de 2 segundos indicadas
[ ] Instrumentos finales mencionados

OVERALL:
[ ] Todo pasa los 9 Must-Have
[ ] Coherencia interna (estructura lógica)
[ ] Age-appropriateness verificada (hoja evaluation-checklist.md)
[ ] Listo para enviar a Mureka
```

## Error Prevention Checklist (Errores más comunes)

Antes de enviar, evita estos:

| Error | Síntoma | Corrección |
|---|---|---|
| Style Prompt en español | Mureka ignora partes | Reescribir completamente en inglés |
| Líneas demasiado largas (8+ palabras) | Niño no entiende | Contar palabras, reducir a máx 6–7 |
| Hook inexistente | Niño se aburre en primeros 5 seg | Agregar pregunta o sorpresa en Verso 1 |
| Coro muy tarde (después seg 20) | Pierde atención antes del gancho | Mover coro a después de Verso 1 |
| Onomatopeyas confusas (¡Lalala!) | Suena extraño | Cambiar a ¡Pam!, ¡Pío!, ¡Splash! |
| Talo completamente pasivo | No hay actividad clara | Releer lyrics, Talo debe "hacer" cosas |
| BPM no especificado | Resultado impredecible | Escribir número específico en Style Prompt |
| Densidad diferente por edad | Demasiado complejo para 2–3 años | Releer edad, ajustar palabras/verso |
| Mix español-inglés en mismo prompt | Confusión, Mureka puede ignorar | Separar Style Prompt (inglés) de Lyrics (español) |
| Pausa sin duración | Mureka ignora intención | Especificar: [Pause 2-second] |

## Keyboard Shortcuts / Common Tasks

Comandos comunes que puede necesitar:

**Crear canción nueva desde cero:**
1. Lee: song-structures.md (elige estructura)
2. Copia: production-templates.md (Plantilla Producción)
3. Verifica: Pre-Submission Checklist (abajo)
4. Envía a Mureka

**Evaluar canción generada:**
1. Ejecuta: evaluation-checklist.md (9 Must-Have primero)
2. Si falla: Ajusta con production-templates.md (Feedback Loop)
3. Si pasa: Ejecuta Should-Have y Nice-to-Have
4. Aprueba o rechaza

**Canción rechazada, no sé qué cambiar:**
1. Lee: examples.md (Ejemplo J — Rechazada)
2. Compara tu canción con problemas del Ejemplo J
3. Usa: production-templates.md (Feedback Loop Rápido)
4. Reescribe con cambios específicos

**Mejorar canción existente:**
1. Lee: examples.md (Ejemplo K — Iteración v1→v3)
2. Sigue el patrón: Identifica problemas → Ajusta → Regenera
3. Registra aprendizaje en: feedback-learning-loop.md

**Análisis rápido de competencia:**
1. Usa: quick-prompts.md (Plantilla D1 o D2)
2. Consulta: competitor-analysis.md (Matriz recomendada por tema)
3. Crea canción diferenciada

**Optimizar para Shorts:**
1. Lee: quick-reference.md (Platform Optimization Matrix)
2. Copia: production-templates.md (SHORT VERSION)
3. BPM: 115–135
4. Hook: Seg 0–2 (crítico)
