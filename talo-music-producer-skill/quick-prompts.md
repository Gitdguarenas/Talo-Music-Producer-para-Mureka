# Quick Prompts — Prompts rápidos para usar Talo Music Producer

## Cómo usar este archivo

Este archivo contiene **plantillas de prompts listos para copiar y pegar**. Solo reemplaza los campos entre corchetes `[así]` con tus datos específicos, y pégalo directamente en la conversación.

No necesitas escribir instrucciones largas cada vez; usa estos prompts como punto de partida y la skill se encargará del resto.

---

## Plantillas completas

### A. Canción completa para Mureka

```
Usa talo-music-producer-skill.
Crea una canción completa para Mureka sobre [TEMA: ej. colores primarios].
Edad objetivo: [2–3 / 3–4 / 4–5 / 5–6 años].
Formato: YouTube Kids.
Duración sugerida: [1:45–2:15].
Incluye:
- Letra en español latino neutro
- Prompt musical para Mureka en inglés
- Versión Short/Reel de 35–45 segundos
- Checklist de evaluación
- Sugerencias visuales / storyboard
```

---

### B. Short / Reel

```
Usa talo-music-producer-skill.
Crea un Short/Reel de [25–45] segundos sobre [TEMA].
Requisitos:
- Gancho en los primeros 3 segundos
- Una sola idea educativa
- Frase repetible
- Cierre en loop o CTA natural
- Prompt Mureka en inglés
```

---

### C. Loop educativo

```
Usa talo-music-producer-skill.
Crea un loop educativo de [45–75] segundos sobre [TEMA].
Debe ser:
- Repetible sin sentir cortado
- Simple y claro
- Con coro identifiable
- Final que conecte naturalmente con el inicio
- Apto para YouTube Kids autoplay
```

---

### D. Canción con análisis de competencia

```
Usa talo-music-producer-skill.
Crea una canción para Mureka sobre [TEMA].
Analiza estas referencias como patrones generales
(estructura, timing, energía, interacción),
sin copiar letras, melodías, estructuras reconocibles ni identidad:
[PEGAR LINKS/TÍTULOS DE REFERENCIAS]

Entrega:
- Análisis de patrones observados
- Riesgos de copia identificados
- Estructura original para Talo
- Letra en español latino
- Prompt Mureka en inglés
- Versión Short/Reel
- Checklist
```

### F. Evaluar una canción generada por Mureka

```
Usa talo-music-producer-skill.
Evalúa esta canción generada por Mureka.
Dime si conviene:
- Aprobar
- Ajustar prompt y regenerar
- Regenerar desde cero
- Rechazar

Evalúa: voz, claridad, tempo, estructura, coro, interacción,
utilidad para video YouTube Kids, viabilidad para Shorts/Reels,
riesgo de copyright.

Canción / resultado:
[PEGAR LETRA O DESCRIPCIÓN DEL AUDIO]

Entrega: score, decisión, problemas principales, cambios concretos.
```

```

[¿En qué segundo? ¿Qué dice o suena?]

[¿Qué aprende el niño?]
```

## Consejos de uso

- **Siempre especifica edad objetivo** — 2–3, 3–4, 4–5 o 5–6 años; la complejidad cambia mucho
- **Indica el formato** — canción completa, Short, loop educativo; cada uno tiene diferentes requisitos
- **Con referencias, sé específico** — pasa links o nombres de canciones; la skill extraerá patrones, no copiará
- **Pide evaluación antes de Mureka** — usa el prompt F para validar antes de enviar a producción
- **Registra aprendizajes** — cada corrección importante se registra en feedback-learning-loop.md para mejorar futuras canciones
- **Una idea a la vez** — si tienes 5 cambios, pasa el prompt E (mejorar letra) una vez; la skill entregará la versión mejorada
- **Copia y pega los prompts** — están listos; solo reemplaza los campos entre `[corchetes]`

---

## Flujo recomendado

1. **Elige un prompt** de las plantillas completas o usa ultra cortos
2. **Reemplaza los campos** con tu información
3. **Pega en la conversación**
4. **La skill entrega** la canción, análisis, prompts y checklist
5. **Si hay cambios**, usa el prompt E o F según lo que necesites
6. **Aprueba y registra** cualquier aprendizaje con el prompt G
7. **Envía a Mureka** con el Style Prompt que entregó la skill
