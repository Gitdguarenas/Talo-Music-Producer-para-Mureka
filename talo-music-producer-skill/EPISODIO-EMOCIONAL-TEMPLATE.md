# EPISODIO EMOCIONAL — TEMPLATE REUTILIZABLE PARA MUREKA

**Este documento es el MAESTRO para entregar episodios emocionales listos para producción.**

Cada vez que el usuario solicite: "Usa el skill y crea una canción para esta idea: [descripción]", seguiré EXACTAMENTE este formato.

## ESTRUCTURA LÍRICA OPTIMIZADA — PATRONES LULI PAMPÍN

**Duración máxima: 3 minutos | Coros pegajosos | Versos concisos**

### ESTRUCTURA BASE (Para todas las canciones)

```
[Intro] — 3-5 seg (hook explosivo)
↓
[Verso 1] — 3 líneas (acción, no narrativa)
[Coro] — 3-4 líneas (pegajoso, se canta involuntariamente)
↓
[Verso 2] — 3 líneas (mismo patrón, elemento varía)
[Coro] — IDÉNTICO (3-4 líneas)
↓
[Verso 3] — 3 líneas (si aplica)
[Coro] — IDÉNTICO (3-4 líneas)
↓
[Outro] — 2-3 líneas (cierre o CTA)

DURACIÓN TOTAL: 2:30–3:00 minutos
```

### Patrón 1: Hook Explosivo en Intro (0-3 seg)
```
✅ BIEN:
"¡Uno, dos, tres!
¡Los cubos aquí!"

❌ MAL:
"Despierto, me levanto..."
```

### Patrón 2: Verso ACCIÓN (no presentación/narrativa)
```
✅ BIEN (acción):
"¡Rojo como la manzana!
¡Splash! ¡Qué bonita!
Amarillo como el sol!"

❌ MAL (presentación):
"Yo soy Talo, el camaleón,
curioso y lleno de imaginación,
pinto, exploro sin parar..."

✅ VERSO CORTO:
- Máximo 3 líneas
- Cada línea máximo 5 palabras
- Acción clara (no descriptiva)
```

### Patrón 3: Coro Pegajoso (3-4 líneas, NO 2)
```
✅ BIEN (pegajoso, 3-4 líneas):
"Respira con Talo,
uno, dos, tres.
Manos tranquilas,
construyen mejor."

O:
"Colores, colores,
¡rojo, azul, amarillo!
¡Qué hermoso es!
¡Mira todo brillar!"

❌ MAL (demasiado corto):
"Respira con Talo" (solo 3 palabras)

❌ MAL (demasiado largo/complejo):
"Somos amigos, ven a conocer,
cada uno especial también,
juntos reímos, juntos aprendemos,
en la aldea felices seremos." (demasiado narrativo)

✅ CORO APARECE 3+ VECES:
(Más coro que verso = pegajosidad)
```

### Patrón 4: Verso Repetidor + Elemento que Varía
```
VERSO REPETIDOR (estructura igual):
"¡Rojo como la manzana!
¡Splash! ¡Qué bonita!
[COLOR] como [OBJETO]"

ELEMENTO QUE VARÍA (entre repeticiones):
Repetición 1: "Amarillo como el sol"
Repetición 2: "Azul como el cielo"
Repetición 3: "Verde como el árbol"

BENEFICIO: Familiaridad + Novedad = Pegajoso
```

### Patrón 5: Onomatopeyas Pegajosas (en primeros 5-10 seg)
```
✅ EJEMPLOS:
"¡Splash!" (agua, alegría)
"¡Pam!" (cubos cayendo, energía)
"¡Pío!" (miedo, pájaros)
"¡Crunch!" (comer, acción)
"¡Whoosh!" (movimiento rápido)

CUÁNDO: Dentro de primeros 10 segundos
DÓNDE: Dentro del verso o hook
```

### Patrón 6: Rimas AABB Simples (no forzadas)
```
✅ NATURAL:
"Rojo como la manzana" / "¡Splash! ¡Qué bonita!"
"Amarillo como el sol" / "¡Mira, mira, brilla!"

❌ FORZADO:
"Despierto, me levanto" / "Estiro, estiro las manos"
(No riman bien, flojo)
```

### Patrón 7: Diálogo/Interacción (Opcional pero recomendado)
```
"¡Hola, Celestino!"
"¿Querés probar?"
"Respira conmigo"
"¿Dónde estás, Talo?"
```

### Patrón 8: Menos Versos Totales (3-4, no 5-6)
```
❌ "SOMOS AMIGOS" (actual):
Intro → Verso 1 (Talo) → Coro → Verso 2 (Nuti) → Coro → Verso 3 (Rubí) → Verso 4 (Tuco) → Coro Final
= 6 versos + muchas presentaciones = LENTO

✅ OPTIMIZADO:
Intro → Verso 1 → Coro → Verso 2 → Coro → Verso 3 → Coro → Outro
= 3 versos + 3 coros = RÁPIDO y PEGAJOSO (duración 2:30-3:00)
```

### Patrón 9: Coro IDÉNTICO en todas las repeticiones (no variaciones)
```
✅ BIEN:
[Coro 1] "Respira con Talo, uno, dos, tres..."
[Coro 2] EXACTAMENTE IGUAL
[Coro 3] EXACTAMENTE IGUAL

❌ MAL:
[Coro 1] "Colores por todos lados..."
[Coro 2] "Colores en el cielo..." (variación)
(Confunde al niño, no es pegajoso)
```

### Patrón 10: Vocabulario Simple (palabras de 1-2 sílabas máximo cuando sea posible)
```
✅ SIMPLE:
Rojo, sol, mar, árbol, viento, agua

❌ COMPLEJO:
Imaginación, características, aldea, aventura
```

### DURACIÓN POR SECCIÓN (Para llegar a 3 min máximo)

```
[Intro] — 5 seg
[Verso 1] — 15 seg (3 líneas × 5 seg/línea)
[Coro] — 15 seg (3-4 líneas × 4-5 seg/línea)
[Verso 2] — 15 seg
[Coro] — 15 seg
[Verso 3] — 15 seg
[Coro] — 15 seg
[Outro] — 10 seg

TOTAL: 105 seg ≈ 1:45–2:30 (CONFORTABLE)

O CON PAUSA EMOCIONAL:
[Pausa silencio] — 2 seg
Total ajustado: 2:00–2:50 minutos
```

## BLOQUE 2: STYLE PROMPT (CRÍTICO — 500 CHARS MAX)

**REGLAS ABSOLUTAS:**

1. **SOLO términos musicales concretos** — No emociones abstractas
   - ✅ BIEN: "85 BPM gentle sections, 115 BPM chaotic chorus, acoustic guitar, ukulele, warm marimba"
   - ❌ MAL: "happy emotional song" o "playful and safe"

2. **Separar zonas de tempo** — Indicar cambios dentro de la canción
   - ✅ BIEN: "starts gentle 85 BPM, builds to 115 BPM chaos, resolves 85 BPM"
   - ❌ MAL: "variable tempo throughout"

3. **Voz específica** — Sin altos, conversacional, cálida
   - ✅ BIEN: "warm female vocal, conversational tone, no high notes, soft to expressive range"
   - ❌ MAL: "happy voice" o "emotional delivery"

4. **Instrumentos concretos** — No descripciones
   - ✅ BIEN: "acoustic guitar, ukulele, warm marimba, soft claps, light glockenspiel"
   - ❌ MAL: "emotional instruments" o "strings"

5. **Referencia estilo (última línea)** — Explicar el "feeling" sonoro total
   - ✅ BIEN: "Inspired by: Bluey emotional episodes, Cocomelon warmth, Luli Pampín energy"
   - ❌ MAL: "Inspired by: sadness and hope"

**TEMPLATE STYLE PROMPT (Copiar y adaptar):**

```
[GENRE], [MOOD PROGRESSION], [BPM RANGES], 
[INSTRUMENTS SPECIFIC], [VOICE DESCRIPTION], 
[PRODUCTION STYLE], [REFERENCE STYLE]
```

**EJEMPLO REAL — Talo y el Color del Enojo:**

```
Warm latin kids pop, emotional narrative song, starts gentle and builds 
to playful chaos then resolves calm. 85 BPM gentle sections, 115 BPM 
chorus chaos, back to 85 BPM resolution. Acoustic guitar, ukulele, 
warm marimba, soft claps, light glockenspiel. Warm female vocal, 
conversational tone, soft to expressive range (no high notes, no 
classical style). Clean organic mix, nursery rhyme storytelling meets 
Bluey emotional depth. Inspired by: Bluey emotional episodes, 
Cocomelon warmth, Luli Pampín energy. Sounds like mom/teacher singing 
to kids in living room, not stage performance.
```

## BLOQUE 3: LYRICS (METATAGS VÁLIDOS SOLO)

**METATAGS VÁLIDOS POR MUREKA:**

```
[Intro] → Introducción suave
[Verse] / [Verse 1] / [Verse 2] / [Verse 3] → Verso
[Pre-Chorus] → Antes del coro (build)
[Chorus] / [Chorus 1] / [Chorus 2] → Coro
[Bridge] / [Bridge 2] → Puente emocional
[Pause] → Pausa/Silencio
[Silence] → Silencio total
[Spoken] → Voz hablada, no cantada
[Call and Response] → Llamada-respuesta
[Final Chorus] → Último coro antes del outro
[Outro] / [End] → Cierre
[Fade Out] → Fade suave
```

**ETIQUETAS DE INTERPRETACIÓN (dentro de metatags):**

```
[soft] [whispered] [energetic] [playful] [spoken] 
[gentle] [building] [intense] [peaceful]
```

**ESTRUCTURA DE 7 FASES EN METATAGS:**

| Fase | Metatags | Función |
|---|---|---|
| **Fase 1: Setup** | `[Intro]` + `[Verse]` | Presenta a Talo feliz, introduce problema |
| **Fase 2: Frustración** | `[Verse]` + `[Pre-Chorus]` | Tensión crece, problema se agrava |
| **Fase 3: Explosión** | `[Pre-Chorus]` + `[Chorus]` | Pico emocional, caos pero SEGURO |
| **Fase 4: Pausa** | `[Pause]` o `[Silence]` | 2 seg silencio total, validación |
| **Fase 5: Intervención** | `[Spoken]` + soft melodía | Guía de regulación muy suave |
| **Fase 6: Resolución** | `[Bridge]` + `[Verse]` | Transformación honesta, calmada |
| **Fase 7: Integración** | `[Final Chorus]` + `[Outro]` | Refrán pegajoso, esperanza |

**EJEMPLO REAL — Talo y el Color del Enojo (Estructura completa):**

```
[Intro - soft, glockenspiel and acoustic guitar]
Talo quiere construir una torre muy alta
con sus bloques de madera que brillan y saltan.

[Verse 1 - gentle storytelling, 85 BPM]
Uno, dos y tres, la torre empieza a crecer
Talo se concentra, hay tanto por hacer.
Pone un bloque verde, luego uno de color azul
la punta ya casi toca la lámpara de luz.

[Verse 2 - tempo increasing, marimba adds rhythm]
La torre se tambalea, un poquito a la derecha
Talo estira el brazo, cada movimiento cuenta.
Cuidado con el borde, cuidado con el pie
el último bloque no se queda donde debería ser.

[Pre-Chorus - energy building, claps enter]
Se tambalea, se tambalea, casi casi se va
Talo respira hondo, intenta otra vez más.
Pero nada, pero nada, no quiere cooperar
la torre se va abajo, se desmorona al azar.

[Chorus - energetic chaos, 115 BPM, playful not scary]
¡Oh no! [clap] ¡Se cayó! [clap]
¡Todo se derrumbó! [light staccato]
¡Qué rabia! [clap] ¡Qué dolor! [clap]
¡El rojo me invadió!

[Chorus repeat - second time, louder]
¡Se rompió! ¡Se cayó! ¡Todo el rojo me invadió!
¡Tengo ganas de gritar! ¡Tengo ganas de saltar!
¡No es justo! ¡No es justo! ¡No es justo!
¡Quiero dejar de intentar!

[Pause]

[Spoken - whispered, very soft, validation]
Está bien estar enojado, Talo.
Tu torre era hermosa y te costó trabajo.
El rojo que sientes es verdadero y está bien.
Pero podemos respirar juntos.

[Bridge - call and response, soft piano, breathing sounds]
Inhalamos por la nariz, como oliendo una flor
[inhale sound]
Exhalamos por la boca, soplando un globo grande
[exhale sound]
El aire entra suave, suave
[inhale]
El aire sale lento, lentamente
[exhale]

[Verse 3 - calm, 85 BPM, warm]
El rojo se apaga, llega el color de la hoja
ya no quema el pecho la emoción que era roja.
Las piezas siguen brillando, esperando en el rincón
con manos tranquilas y mucha atención.
Talo busca el verde, busca el azul
vuelve la calma bajo la luz.

[Verse 4 - gentle, hopeful]
Uno, dos y tres, empezamos otra vez
Despacio, muy despacio
Paso a paso, con calma.
Las piezas vuelven a crecer.

[Final Chorus - warm, memorable, 85 BPM]
Respira con Talo, uno, dos y tres
Cuando te sientas mal, puedes calmarte también.
Respira con Talo, uno, dos y tres
El rojo se va yendo, vuelve el verde otra vez.

[Bridge 2 - integration, soft]
No hace falta que sea perfecta
Solo hace falta intentar.
Talo lo sabe ya:
Está bien no lograrlo,
está bien volver a empezar.

[Outro - gentle fade, 85 BPM, acoustic guitar]
Y aunque los bloques se caigan otra vez
Talo nunca deja de aprender.
Las manos tranquilas construyen mejor

¡Hasta luego, amiguito!
Vuelve cuando necesites respirar.

[End - soft exhale sound, fade to silence]
```

```markdown
[Listar sonidos específicos y dónde van]

### Critical Moments

### Interactivity
[Dónde el niño respira/participa/procesa]

### Visual Guidance
[Cambios de color, movimientos de Talo]
```

**EJEMPLO REAL:**

```markdown
### Tempo Progression
- [Intro] → 85 BPM, very soft, establishing
- [Verse 1] → 85 BPM, steady, building anticipation
- [Verse 2] → 95 BPM, tension increases
- [Pre-Chorus] → 105 BPM, energy rising
- [Chorus] → 115 BPM, chaos but playful
- [Pause] → 0 BPM, complete silence, 2 seconds
- [Spoken] → 80 BPM, very slow, validating
- [Bridge] → 85 BPM, breathing cues
- [Verse 3-4] → 85 BPM, calm and hopeful
- [Final Chorus] → 85 BPM, warm and memorable
- [Outro] → 85 BPM, soft fade

### Dynamic Progression
- [Intro] → pp (very soft, almost whispered)
- [Verse 1-2] → p to mp (soft to medium-soft)
- [Pre-Chorus] → mp to mf (building)
- [Chorus] → mf to f (energetic but NOT aggressive)
- [Pause] → silence
- [Spoken] → pp (whispered validation)
- [Bridge] → p (breathing guide, very gentle)
- [Verse 3-4] → p to mp (warm, calm)
- [Final Chorus] → mp to mf (memorable but warm)
- [Outro] → pp (fade to silence)

### Sound Effects
- [Intro] Glockenspiel notes (2-3 light notes, 2 sec)
- [Verse 1] Soft ukulele strumming (background throughout)
- [Verse 2] Marimba enters, rhythm on beat 2
- [Pre-Chorus] Hand claps on beats 1 and 3
- [Chorus 1] Staccato marimba, playful chaos (NOT aggressive)
- [Pause] 2 seconds absolute silence
- [Spoken] Natural breathing sounds, very subtle
- [Bridge] Breathing inhale/exhale sounds (realistic but gentle)
- [Verse 3-4] Acoustic guitar returns, warm tone
- [Final Chorus] Full instrumentation, but warm and integrated
- [Outro] Soft acoustic fade, no harsh endings

### Critical Moments
1. **[Pause] Absolute Silence (0:45-0:50)**
   - Must be TOTAL silence (not ambience, not reverb)
   - Duration: exactly 2 seconds
   - Purpose: Allows child to feel emotion without overwhelm

2. **[Spoken] Validation (0:50-0:65)**
   - Voice must be VERY soft, nearly whispered
   - Tone: understanding adult, not condescending
   - Never minimize ("it's okay to be angry")
   - Always validate ("your anger is real and okay")

3. **[Chorus] Chaos Quality (0:30-0:45)**
   - Chaos must be PLAYFUL, not scary
   - No aggressive drums, no harsh strings
   - Rhythm can be "messy" but must stay METRIC
   - Dynamics: mf (medium-loud) not ff (very loud)

4. **[Final Chorus] Refrain Memorability (1:50-2:10)**
   - Must be simple, singable, repetitive
   - "Respira con Talo" appears 2-3 times
   - Melody must be WARM (not bright/piercing)
   - No complex harmonies, clean and clear

### Interactivity
- **[Intro]** — Child watches Talo start building (observer)
- **[Verse 1-2]** — Child can follow Talo's concentration (engagement)
- **[Chorus peak]** — Child can shout with Talo (emotional release, not scary)
- **[Pause]** — Child FEELS the emotion in silence (processing)
- **[Spoken]** — Adult validates child's anger (connection)
- **[Bridge]** — Child BREATHES with Talo (1-2-3 inhale, 1-2-3 exhale)
- **[Verse 3-4]** — Child can see Talo rebuild calmly (modeling)
- **[Final Chorus]** — Child sings refrain "Respira con Talo" (integration)

### Visual Guidance
| Momento | Color Talo | Acción | Movimiento |
|---|---|---|---|
| [Intro] | Amarillo/Verde natural | Construye con enfoque | Movimientos lentos, deliberados |
| [Verse 1] | Verde | Concentración | Brazos extendidos, estable |
| [Verse 2] | Verde → Naranja | Tensión aumenta | Movimientos más rápidos |
| [Pre-Chorus] | Naranja | Frustración | Movimientos nerviosos |
| [Chorus 1] | Rojo intenso | Explosión emocional | Giros rápidos, brazos abiertos |
| [Chorus 2] | Rojo oscuro | Caos emocional | Movimientos desordenados pero claros |
| [Pause] | Rojo congelado | Pico emocional | Completamente congelado |
| [Spoken] | Rojo → Naranja | Validación | Respiración visible, lento |
| [Bridge] | Naranja → Amarillo | Regulación | Respiración profunda, brazos bajados |
| [Verse 3] | Verde | Calma | Movimientos suave, deliberado |
| [Verse 4] | Verde + Azul | Esperanza | Movimientos más amplios, abiertos |
| [Final Chorus] | Verde + Azul + Amarillo | Paz integrada | Construcción lenta, confiada |
| [Outro] | Multicolor armónico | Aprendizaje | Reposo, sonrisa, conexión |
```

## BLOQUE 5: NEGATIVE GUIDANCE (POR EMOCIÓN)

**Propósito:** Decirle explícitamente a Mureka qué NO hacer.

**ENOJO/FRUSTRACIÓN:**
```
Avoid: aggressive drums, harsh strings, screaming vocals, heavy percussion, 
scary sounds, rapid tempo throughout, triumphant endings, aggressive 
snare hits, loud explosions, dark mood, overly complex rhythms, 
distorted instruments.
```

**MIEDO:**
```
Avoid: horror movie strings, sudden loud noises, creepy sounds, 
overwhelming silence (use 2 sec only), ghost sounds, jump scares, 
dark and heavy minor keys only, evil laughter, chaotic non-metric 
rhythm, overly tense atmosphere without resolution pathway.
```

**TRISTEZA:**
```
Avoid: depressive atmosphere that doesn't lift, hopelessness, 
overly slow throughout (provide tempo changes), dark minor key 
only, no resolution, heavy strings without warmth, funeral-like 
tone, complete hopelessness in lyrics or music, no light.
```

**CELOS/RIVALIDAD:**
```
Avoid: aggressive confrontation, violent imagery, competitive/mean 
tone, music that sounds angry instead of sad, character shaming, 
no pathway to inclusion, dark revenge overtones, mean-spirited melody.
```

**VERGÜENZA:**
```
Avoid: judgment in vocal tone, condescending lyrics, overly dark mood, 
no validation, shaming language ("you should know better"), complex 
self-analysis beyond 6 years old, isolation without redemption pathway, 
classical tone (should be warm/accessible).
```

**SOLEDAD:**
```
Avoid: complete hopelessness, no connection offered, overly melancholic 
throughout, eerie sounds, isolation emphasized without community, 
no echo/harmony (use vocals to show connection), dark and lonely 
atmosphere that lingers, no resolution.
```

## CHECKLIST DE VALIDACIÓN EMOCIONAL

Antes de entregar, verificar:

- [ ] **Validación clara** — La emoción se reconoce, no se minimiza (no "no te enojes", sí "está bien estar enojado")
- [ ] **NO es terapia** — No es análisis adulto, es reconocimiento infantil simple
- [ ] **Pausa emocional real** — Silencio EXACTO de 2 segundos en el pico emocional, metatag `[Pause]` o `[Silence]`
- [ ] **Interactividad emocional** — El niño respira CON Talo, no solo canta (en `[Bridge]` o similar)
- [ ] **Resolución honesta** — No es perfección, es aprendizaje (no "ahora todo está bien", sí "Talo aprendió a calmarse")
- [ ] **Refrán memorable** — Frase se canta involuntariamente, aparece 2-3 veces, es simple
- [ ] **Leitmotif transformador** — Motivo musical cambia de frustración → calma dentro del mismo episodio
- [ ] **Cambios visuales** — Colores reflejan transformación emocional (Rojo → Verde)
- [ ] **Mensaje para padres** — Los adultos se ven reflejados en Talo (conexión emocional auténtica)
- [ ] **NO agresivo o asustador** — El caos es emocional, no físico. Reconocible y seguro
- [ ] **Metatags válidos SOLO** — Sin descripciones de acciones en brackets (ej: NO `[Talo abre ojos]`)
- [ ] **Style Prompt separado** — 500 chars máximo, términos musicales concretos, NO emociones abstractas
- [ ] **Duración correcta** — 2:30–3:30 min (típicamente)
