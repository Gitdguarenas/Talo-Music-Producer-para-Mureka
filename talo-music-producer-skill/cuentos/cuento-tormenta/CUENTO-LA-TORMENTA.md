# LA TORMENTA — Cuento Ilustrado
## Prompts Nano Banana 2 para Libro Infantil

**Estilo:** Anne-Marie Chapouton (Patapan, Tilly y sus amigos)  
**Formato:** 24 páginas (Portada + 22 interiores + Contraportada)  
**Protagonistas:** Talo, Rubí  
**Mundo:** Aldea TaloInsta, casa de Talo  
**Público:** 2-6 años

---

## PORTADA

```
COMPOSICIÓN VISUAL:
- Centro: Talo mira por ventana, lluvia visible afuera
- Rubí está junto a Talo, tranquilizadora
- Ventana con gotas de lluvia (toc, toc, toc)
- Nubes grises pero no aterradoras
- Luz cálida adentro contrasta con tormenta afuera
- Cortinas parcialmente cerradas para protección
- Expresión de Talo: curioso pero nervioso

TÍTULO CENTRAL (tipografía estilo Chapouton):
"LA TORMENTA"
(Subtítulo: "Talo aprende a no tener miedo")

ELEMENTOS VISUALES:
- Lluvia visible en ventana
- Nubes grises suaves
- Luz cálida filtrando la habitación
- Rubí siendo protectora/calmante
- Gotas de lluvia como ritmo visual

ESTILO:
- Watercolor/ilustración suave, líneas claras
- Paleta: grises suaves, azules de lluvia, naranjas cálidos, verdes
- Textura: tela/papel antiguo (estilo Chapouton)
- Clima: tormenta afuera, calma adentro
- Sin amenaza real, ambiente de protección
```

## PÁGINA 1

```
COMPOSICIÓN VISUAL:
- Talo en ventana, mirando afuera
- Gotas de lluvia caen lentamente
- Cielo grisáceo pero suave
- Rubí cerca, observando con Talo
- Sonidos sutiles representados (toc, toc, toc)
- Luz cálida adentro

TEXTO (máx 2 líneas):
"Toc, toc, toc, la lluvia cae.
Talo mira la ventana."

ESTILO:
- Curioso, tranquilo aún
- Colores cálidos adentro, grises suaves afuera
- Ritmo visual de lluvia
```

## NOTAS DE ESTILO PARA TODAS LAS PÁGINAS

**Tipografía (Anne-Marie Chapouton):**
- Títulos: Fuente redondeada, amigable
- Texto: Legible, tamaño infantil grande
- Diálogos: Diferenciados (Talo vs. Rubí sutilmente)

**Color y Atmósfera:**
- Paleta: Grises suaves (lluvia), azules (tormenta), naranjas/amarillos (calidez interior)
- Luz: Cálida adentro, dramática afuera (contraste)
- Textura: Acuarela suave, papel envejecido tipo Chapouton
- Tormenta: Dramática pero nunca aterradora gráficamente
- Lluvia: Representada como patrón visual hermoso (toc, toc, toc)

**Composición:**
- Talo siempre reconocible (espiral amarilla visible)
- Rubí roja consistente y protectora
- Ventana como elemento central del conflicto
- Cortinas y música como soluciones visuales
- Emociones claras en expresiones faciales

**Narrativa Visual:**
- Páginas 1-9: Escalación de miedo hasta pico
- Páginas 10-16: Aprendizaje de herramientas
- Páginas 17-22: Transformación y maestría
- Ritmo: Curiodad → Miedo → Enseñanza → Seguridad

**Referencias de Estilo:**
- Anne-Marie Chapouton: Watercolor, tiernura, naturaleza integrada
- Tormenta como personaje secundario (importante pero controlable)
- Enfoque en empoderamiento a través de herramientas prácticas
- Validación + Acción = Resolución
