# Evaluation Checklist — Control de calidad para canciones de Talo

## Cómo usar este checklist

Este checklist se aplica en tres momentos distintos del flujo de producción:

1. **Antes de enviar a Mureka** — verificar que la letra y el prompt están listos para generar
2. **Después de recibir el audio generado** — evaluar el resultado de Mureka contra los criterios de calidad
3. **Antes de publicar o crear video** — validación final antes de animación, edición y publicación

Completar todas las secciones relevantes según el momento. No todas las secciones aplican igual en cada etapa.

---

## Sistema de decisión

| Resultado | Criterio | Acción |
|---|---|---|
| **Aprobada** | Score 90–100, sin riesgos de copyright | Proceder a producción / video |
| **Ajustar letra / prompt** | Score 75–89 o problemas menores específicos | Corregir los ítems fallidos y reenviar a Mureka |
| **Regenerar en Mureka** | Score 60–74 o problemas estructurales en el audio | Ajustar prompt completo y regenerar desde cero en Mureka |
| **Rechazar** | Score menor a 60, riesgo de copyright alto, tono inadecuado | Descartar y recomenzar con nuevo enfoque creativo |

> Riesgo de copyright alto = rechazar aunque el score sea bueno en otras categorías.

---

## A. Marca e identidad Talo

- [ ] La letra usa español latino neutro (sin modismos regionales marcados)
- [ ] El tono es cálido, seguro y familiar para niños de 2–6 años
- [ ] La presencia de Talo en la letra es natural, no forzada
- [ ] No hay referencias a marcas externas, violencia, miedo ni temas inapropiados
- [ ] El mensaje educativo es claro y simple
- [ ] El estilo es consistente con el universo de El Mundo de Talo

**Ítems: 6**

---

## B. Objetivo educativo

- [ ] Hay un solo objetivo educativo principal (no mezclar colores + números + emociones en una canción)
- [ ] El vocabulario es apropiado para la edad objetivo (2–6 años)
- [ ] El aprendizaje ocurre dentro de un juego, historia o actividad — no como clase rígida
- [ ] La palabra o concepto clave se repite al menos 3 veces en la canción
- [ ] El niño puede identificar qué aprendió sin que se lo declaren explícitamente

**Ítems: 5**

---

## C. Letra y cantabilidad

- [ ] Las frases cantadas tienen entre 4 y 8 palabras por línea
- [ ] Las palabras del hook son de 1–3 sílabas
- [ ] El coro es fácil de repetir en las primeras 2 escuchas
- [ ] La densidad de palabras es baja (espacio para respirar entre frases)
- [ ] Hay pausas suficientes para que el niño procese o responda
- [ ] La pronunciación es clara y sin palabras ambiguas
- [ ] No hay exceso de texto en ninguna sección

**Ítems: 7**

---

## D. Estructura musical

- [ ] El gancho aparece en los primeros 0–10 segundos
- [ ] El primer coro entra idealmente antes de los 20 segundos, y nunca después de los 30
- [ ] La intro dura 10 segundos o menos
- [ ] El coro se repite al menos 3 veces (versión larga) o 2 veces (Short)
- [ ] Hay al menos un cambio de energía claro entre secciones
- [ ] El cierre es memorable o permite loop natural

**Ítems: 6**

---

## E. Producción para Mureka

- [ ] Las etiquetas de sección están en inglés (`[Intro]`, `[Verse]`, `[Chorus]`, `[Final Chorus]`, etc.)
- [ ] El prompt musical está escrito en inglés
- [ ] El estilo musical está bien definido (genre tags, mood tags)
- [ ] Se indicó BPM sugerido o descripción de tempo
- [ ] Los instrumentos solicitados son apropiados para canciones infantiles
- [ ] El tipo de voz está especificado (edad, género, acento)
- [ ] Se incluyó Negative Guidance si hay riesgos de resultado adulto o incorrecto
- [ ] Las instrucciones de producción están en el Style Prompt, no dentro de las lyrics

**Ítems: 8**

---

## F. Interacción infantil

- [ ] Hay al menos una pregunta directa al niño
- [ ] Hay al menos una instrucción de movimiento corporal
- [ ] Hay al menos una pausa de respuesta ([Pause] de 1.5–3 segundos)
- [ ] Las onomatopeyas presentes aportan valor expresivo o participativo
- [ ] Si aplica, hay un momento de call-and-response claro
- [ ] El clip puede funcionar con participación familiar (padre/madre canta con el niño)

**Ítems: 6**

---

## G. Ritmo, arreglo y retención

- [ ] El BPM es adecuado para el tipo de canción y la edad objetivo
- [ ] La energía de cada sección es coherente con su función
- [ ] Hay al menos un micro cambio de textura o instrumento cada 15–25 segundos
- [ ] El [Chorus] tiene más capas de producción que el [Verse]
- [ ] El bridge o pausa no genera aburrimiento ni desconexión
- [ ] El primer tercio de la canción (0:00–0:40) es el más fuerte

**Ítems: 6**

---

## H. Shorts / Reels

- [ ] Existe o está planificada una versión corta de 25–45 segundos
- [ ] La versión corta tiene una sola idea educativa
- [ ] El hook de la versión corta aparece en los primeros 3 segundos
- [ ] Hay una frase repetible identificada para el clip corto
- [ ] El cierre de la versión corta permite loop o tiene CTA natural
- [ ] La duración de la versión corta está dentro del rango recomendado

**Ítems: 6**

---

## I. Visual / storyboard

- [ ] Cada sección principal sugiere una acción visual clara
- [ ] La letra es sincronizable con animación o ilustración
- [ ] Hay momentos identificados para cambio de escena o plano
- [ ] Los gestos descritos en la letra son simples de animar o de imitar
- [ ] La canción tiene potencial visual para producción de video

**Ítems: 5**

---

## J. Copyright y diferenciación

- [ ] No se copia melodía, letra ni estructura demasiado reconocible de otra canción
- [ ] No se imita directamente ningún artista, canal o personaje conocido
- [ ] Las referencias de competencia se usaron solo para extraer patrones generales
- [ ] La identidad visual y sonora de Talo es diferenciada
- [ ] La distancia creativa respecto a las referencias es suficiente

**Ítems: 5**

---

## K. Evaluación del audio generado

*(Completar solo después de recibir resultado de Mureka)*

- [ ] La voz se entiende con claridad en toda la canción
- [ ] La letra cantada coincide razonablemente con lo escrito
- [ ] El tempo funciona correctamente para niños de 2–6 años
- [ ] El coro destaca claramente sobre los versos
- [ ] No hay artefactos de audio, cortes extraños ni glitches
- [ ] El sonido no es adulto, oscuro ni agresivo
- [ ] La canción mantiene la atención durante toda su duración
- [ ] El resultado es apto para producción de video infantil

**Ítems: 8**

---

## Score recomendado

Contar el total de ítems marcados sobre el total aplicable:

| Score | Estado | Acción |
|---|---|---|
| **90–100%** | Aprobada | Proceder a producción de video |
| **75–89%** | Ajustes menores | Corregir ítems fallidos, no regenerar completo |
| **60–74%** | Ajustes mayores | Revisar letra o prompt y regenerar en Mureka |
| **Menos de 60%** | Regenerar desde cero | Replantear enfoque creativo completo |
| **Riesgo copyright alto** | Rechazar | Descartar aunque el score total sea bueno |

> **Total de ítems por sección:** A(6) + B(5) + C(7) + D(6) + E(8) + F(6) + G(6) + H(6) + I(5) + J(5) + K(8) = **68 ítems totales**
> Para evaluación pre-Mureka (sin K): 60 ítems.

---

## Diagnóstico rápido

| Problema detectado | Causa probable | Acción recomendada |
|---|---|---|
| **El coro no engancha** | Hook débil, coro tardío o melodía poco memorable | Reescribir el coro; moverlo antes del segundo 20 |
| **La letra no se entiende** | Demasiadas palabras, BPM muy alto o pronunciación poco clara | Reducir densidad; bajar BPM; pedir pronunciación clara en Style Prompt |
| **Suena demasiado adulta** | Instrumentación compleja, vocabulario adulto o BPM inadecuado | Simplificar arreglo; revisar vocabulario; ajustar BPM |
| **Muy lenta o aburrida** | BPM bajo, falta de micro cambios, verso sin energía | Aumentar BPM; agregar capa rítmica; introducir variación cada 20 seg |
| **Demasiadas palabras** | Versos densos, frases largas, exceso de información | Cortar versos; elevar espacios; reducir a 1 idea por sección |
| **No sirve para Short** | Sin hook claro, coro tardío o demasiadas ideas | Identificar frase clave; extraer solo coro + una idea; diseñar cierre loop |
| **Parece una canción conocida** | Estructura o melodía demasiado similar a referente | Aumentar distancia creativa; cambiar tempo, tonalidad y estructura |
| **Audio con artefactos** | Prompt con instrucciones contradictorias o Mureka saturado | Simplificar Style Prompt; regenerar con menos instrucciones simultáneas |
| **Niño no puede participar** | Sin pausas, sin preguntas, sin movimientos | Agregar [Pause], instrucción de movimiento y al menos una pregunta |
| **Final abrupto** | Outro demasiado corto o sin diseño de loop | Alargar outro; diseñar cierre que conecte con intro |

---

## Salida esperada del evaluador

Cuando Claude evalúa una canción usando este checklist, debe devolver:

1. **Score estimado** — porcentaje aproximado de ítems cumplidos por sección
2. **Decisión** — Aprobada / Ajustar letra-prompt / Regenerar / Rechazar
3. **Problemas principales** — máximo 3 problemas críticos identificados, en orden de impacto
4. **Cambios concretos** — qué líneas, secciones o instrucciones cambiar exactamente
5. **Recomendación de acción** — si conviene ajustar el prompt, reescribir la letra o regenerar completo
6. **Versión corregida** — si aplica, entregar lyrics o Style Prompt corregido listo para usar

Formato de salida sugerido:

```
Score estimado: XX%
Decisión: [Aprobada / Ajustar / Regenerar / Rechazar]

Problemas principales:
1. ...
2. ...
3. ...

Cambios concretos:
- ...
- ...

Acción recomendada:
...

[Versión corregida si aplica]
```
