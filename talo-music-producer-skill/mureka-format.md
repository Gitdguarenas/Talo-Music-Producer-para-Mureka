# Mureka Format — Cómo preparar canciones para Mureka

## ¿Qué es Mureka?

Mureka es una plataforma de generación musical con IA. Para obtener resultados de calidad, las instrucciones deben ser precisas y bien estructuradas.

## Campos principales del prompt en Mureka

### 1. Título
Nombre descriptivo de la canción. Incluir tema y emoción si es posible.

### 2. Lyrics (Letra)
Formato estructurado con etiquetas de sección:

```
[Intro]
...

[Verse 1]
...

[Chorus]
...

[Verse 2]
...

[Chorus]
...

[Bridge] (opcional)
...

[Outro]
...
```

### 3. Style / Genre Tags
Géneros y estilos en inglés, separados por coma. Ejemplos:
- `children, educational, pop, upbeat, latin`
- `kids song, playful, acoustic, spanish`
- `nursery rhyme, animated, cheerful`

### 4. Mood Tags
Estado emocional de la canción. Ejemplos:
- `happy, energetic, fun, playful`
- `calm, warm, soothing`

### 5. Tempo indicativo
Describir en palabras: `slow`, `moderate`, `upbeat`, `fast`
O indicar BPM aproximado si se conoce.

### 6. Instrucciones adicionales (notas al productor)
Sección libre para indicar:
- Instrumentos deseados (xilófono, piano, guitarra acústica)
- Cambios de energía por sección
- Efectos especiales (onomatopeyas, coros de niños, aplausos)

## Buenas prácticas

- Las etiquetas de sección deben estar en inglés (`[Chorus]`, `[Verse]`, etc.)
- El texto de la letra puede estar en español
- Ser específico en el mood de cada sección
- Indicar si hay partes habladas vs. cantadas
