# Examples — Biblioteca de ejemplos para Talo Music Producer

## Cómo usar estos ejemplos

Los ejemplos de este archivo sirven como **referencia de formato y estructura**, no como canciones finales obligatorias. Cada producción real debe adaptarse según:

- El tema educativo específico de la canción
- La edad objetivo dentro del rango 2–6 años
- La energía y formato de publicación
- El análisis de competencia del momento
- Las instrucciones del usuario en cada sesión

Usar estos ejemplos para entender cómo se ve una entrega completa, cómo se estructura el Style Prompt y cómo se aplica el flujo de la skill en la práctica.

## A. Canción completa — Colores

**Prompt para Claude**
```
Crea una canción educativa para El Mundo de Talo sobre los colores primarios
(rojo, azul, amarillo). Duración objetivo: 2:00 min. Formato: canción completa
para YouTube Kids. Niños de 3–5 años. Incluir onomatopeyas, pausas interactivas
y una parte donde el niño señale objetos de cada color.
```

| Campo | Valor |
|---|---|
| **Objetivo educativo** | Identificar los tres colores primarios con objetos cotidianos |
| **Edad objetivo** | 3–5 años |
| **Duración sugerida** | 2:00–2:15 min |
| **BPM sugerido** | 105 |

**Estructura con metatags**
```
[Intro] → [Verse 1] → [Chorus] → [Verse 2] → [Chorus] → [Bridge] → [Final Chorus] → [Outro]
```

**Letra**
```
[Intro]
¡Hola, hola! Soy Talo
¡vamos a buscar color!

[Verse 1]
El rojo, rojo, rojo
es el tomate y la manzana
el rojo es muy bonito
¡mira cuánto rojo hay! ¡Ñam!

[Chorus]
¡Rojo, azul, amarillo!
pinta el mundo con Talo
¡búscalos tú también
por toda tu casa hoy!

[Verse 2]
El azul es el del cielo
y también del gran océano
¡Splash! dice el agua fría
cuando Talo salta ¡Splash!

[Chorus]
¡Rojo, azul, amarillo!
pinta el mundo con Talo
¡búscalos tú también
por toda tu casa hoy!

[Bridge]
[Spoken] ¿Puedes señalar algo rojo?
[Pause]
[Spoken] ¿Y algo azul?
[Pause]
[Spoken] ¿Encontraste el amarillo?
¡Muy bien, muy bien!

[Final Chorus]
¡Rojo, azul, amarillo!
pinta el mundo con Talo
¡búscalos tú también
por toda tu casa hoy!

[Outro]
¡Con Talo aprendes más!
¿Lo hacemos otra vez?
```

**Style Prompt para Mureka**
```
Bright Spanish Latin children's educational song for Talo, a curious little
chameleon who loves colors, designed for ages 3–5, warm and friendly female
voice with children backing vocals on chorus, neutral Latin accent, 105 BPM,
happy and energetic mood, featuring xylophone, ukulele, acoustic guitar and
hand claps, soft percussion, build energy from verse to chorus, children
choir on all chorus repetitions, short pause before final chorus, bright
and clean production.
```

**Negative Guidance**
```
Avoid dark mood, heavy drums, adult romantic tone, complex melodies,
regional slang, overly dense verses, long instrumental intro over 5 seconds.
```

**Production Notes**
```
Add "Ñam" sound effect after verse 1. Add water splash sound after "Splash"
in verse 2. Short silence (1.5 sec) after each [Pause] tag. Applause at
start of [Final Chorus]. Friendly, warm outro tone.
```

## H. Ejemplo de análisis de competencia aplicado

**Referencia ficticia:** *Canción infantil viral de colores — referencia genérica*
*(No representa ninguna canción real; es un patrón compuesto para ilustrar el proceso)*

```
Canción / referencia: Canción infantil viral de colores — referencia genérica
Canal / fuente: Canal infantil hispano (ficticio)
Duración total: 2:10 min
Entrada del coro: segundo 18
BPM estimado: 108
Estructura observada: Intro → Verso → Coro → Verso → Coro → Puente interactivo → Coro final → Outro
```

**Patrones observados:**
- Coro muy temprano (seg 18); la frase del coro es de 4 palabras
- Onomatopeya al final de cada verso (alta participación)
- Pausa de 2 seg antes del coro final (efecto de anticipación)
- Percusión marcada en coro vs. suave en verso
- Coros infantiles en todas las repeticiones del coro

**Riesgos de copia:**
- La melodía del coro es muy reconocible; no replicar
- La estructura es casi idéntica a la Estructura A de esta skill; usarla como validación, no como copia
- Las onomatopeyas específicas usadas son características de esa canción; usar onomatopeyas distintas

**Cómo transformarlo para Talo:**
- Mantener: coro antes del segundo 20, pausa dramática antes del coro final, coros infantiles
- Cambiar: melodía completamente original, onomatopeyas propias del tema de Talo, protagonista es Talo el camaleón
- Agregar: momento de call-and-response que esa referencia no tiene

**Estructura original resultante para Talo:**
```
[Intro]          0:00–0:08  Gancho con nombre de Talo
[Verse 1]        0:08–0:20  Presenta concepto educativo
[Chorus]         0:20–0:35  Coro original (antes del seg 20)
[Verse 2]        0:35–0:50  Amplía con ejemplos
[Chorus]         0:50–1:05  Repetición
[Call and Response] 1:05–1:20  Momento propio de Talo, no en la referencia
[Silence]        1:20–1:22  Pausa dramática inspirada en el patrón observado
[Final Chorus]   1:22–1:40  Coro con máxima energía
[Outro]          1:40–1:50  Cierre de Talo
```

## I. Ejemplo de evaluación post-Mureka

**Canción evaluada:** *Los Colores de Talo — versión generada por Mureka (ficticia)*

```
Score estimado: 72%
```
